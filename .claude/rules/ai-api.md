# Anthropic API 사용 규칙

- 호출 지점은 두 곳만: 분석·추천 버튼, 완독 후 토론(첫 질문 자동 요청 포함). 새 호출 지점을 만들지 않는다.
- Messages API를 앱에서 직접 호출한다. 키는 `SecretStore`에서 읽는다. 중계 서버 없음.
- 모델 ID·단가는 저장소 문서를 믿지 말고 T-003 결과(`docs/tasks/T-003.md`)와 공식 문서로 확인한다. 기본 Haiku, 설정에서 Sonnet.
- `max_tokens`: 토론 400, 분석 2000.
- 토론: system 블록은 [역할 프롬프트, 책 컨텍스트] 두 개. 책 컨텍스트에 `cache_control: {"type": "ephemeral"}`. 매 턴 메시지 배열 전체를 보낸다. 사용자 메시지 20개 도달 시 마무리 지시를 붙이고 `endedAt`을 기록한다.
- 분석: 출력은 JSON만. 파싱 실패 시 펜스·앞뒤 텍스트 제거 후 재파싱, 그래도 실패하면 원문을 `taste`로 저장하고 `recommendations`는 빈 배열. 증분 전송·샘플링 금지.
- 오류 처리: 401은 설정 화면 안내, 네트워크·5xx는 재시도 버튼, 자동 재시도는 1회. 로딩 중 중복 호출 차단.
- 호출마다 월별 카운터를 올린다.
- 프롬프트 텍스트는 코드가 아닌 리소스 파일로 관리한다.
- 토론 메시지는 매 턴 즉시 `messagesJson`에 저장한다. 전송 실패 메시지는 "전송 안 됨" 상태로 보관하고 재전송 버튼을 둔다.
