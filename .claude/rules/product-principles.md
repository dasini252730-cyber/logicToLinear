# 제품 원칙 (요구사항에서 사용자가 확정한 것)

원문: `docs/요구사항.md`. 여기 적힌 것을 바꾸려면 코드를 고치기 전에 사용자 확인을 받는다.

## 위반 금지

1. 앱을 열면 2초 안에 카메라가 떠야 한다. 홈 화면은 카메라다.
2. 타이핑은 책 제목 검색, 한 줄 소감, OCR 실패 시 페이지 번호 세 곳에만 허용한다. 다른 텍스트 입력을 추가하지 않는다.
3. 사용자는 한 명. 로그인·서버·계정·중계 서버·클라우드 동기화를 만들지 않는다. 데이터는 기기 로컬 Room DB에만 둔다.
4. AI 호출은 사용자가 버튼을 눌렀을 때만. 백그라운드·자동 호출 금지, 자동 재시도는 1회만.
5. 사진 원본은 저장하지 않는다. OCR 후 비트맵은 메모리에서 폐기하고 추출된 텍스트만 저장한다.
6. API 키(알라딘 TTB, Anthropic)는 설정 화면에서 사용자가 입력해 EncryptedSharedPreferences에 저장한다. 코드·리소스·로그·백업 파일에 넣지 않는다.

## 사용자 확인 없이 바꾸면 안 되는 결정

- 책 상태는 WANT / READING / DONE 셋뿐. 시작일·읽은 기간은 기록하지 않는다. 완독일 하나만.
- 소감은 별점(1~5) + 한 줄(100자). 긴 리뷰 필드 없음.
- 분석·추천은 DONE 책 3권 이상 + 글귀 10개 이상일 때만 활성.
- 토론은 AI가 먼저 질문, 사용자 최대 20턴(메시지 40개), 전체 대화 저장.
- AI 모델은 Haiku 기본, 설정에서 Sonnet 선택. 프롬프트 캐싱 사용. max_tokens 토론 400, 분석 2000.
- 토큰 절약용 증분 전송·샘플링은 하지 않는다. 매번 전체 데이터를 보낸다. 사용자가 명시적으로 거부했다.
- 백업은 수동 JSON 내보내기/가져오기만.
- 외부 의존은 OCR(ML Kit), 도서 검색(알라딘), AI(Anthropic) 셋. HTTP 클라이언트는 T-006에서 확정.

## 범위 밖 (요청이 와도 사용자 확인 없이 추가 금지)

로그인·계정·서버·동기화 / iOS·태블릿 레이아웃 / 전자책 하이라이트 가져오기 / 사진 원본 보관·밑줄 자동 감지 / 읽은 기간·독서 통계·독서 목표 / 공유·SNS 내보내기 / 토론 음성 입력 / 증분 분석·샘플링.

## 사용자 노출 문구

오류·안내 문구는 요구사항 "예외 처리" 표의 표현을 그대로 쓴다. 예: "글자를 찾지 못했어요. 더 밝은 곳에서 다시 찍어 주세요", "이미 서재에 있어요", "읽는 중인 책을 먼저 등록하세요".
