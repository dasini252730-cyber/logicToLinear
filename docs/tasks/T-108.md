## 작업 메모

(2026-10-05)

- Navigation Compose 2.10.2 타입 안전 라우트. `ui/navigation/Routes.kt`에 `HomeRoute`·`LibraryRoute`·`AnalysisRoute`·`SettingsRoute`(object)와 `BookDetailRoute(bookId)`·`BookFormRoute(initialTitle?)`(data class)를 `@Serializable`로 선언. 라우트는 이 파일에만 둔다.
- 하단 탭은 요구사항 표대로 **3개(서재/분석·추천/설정)**. 처음엔 카메라 탭을 더해 4개로 만들었으나 리뷰(차단 2)에서 요구사항 표·완료 조건과 다르다고 지적받아 3개로 되돌렸다. 카메라로 돌아가는 길은 시스템 뒤로가기다: 탭 전환이 시작 화면(카메라)까지 `popUpTo`하므로 어느 탭에서든 뒤로 한 번이면 카메라다. 하단 탭은 카메라 홈과 탭 화면 3개에서 보이고 책 상세·등록·문장 선택에서는 숨긴다.
- 탭 전환은 `popUpTo(start) { saveState } + launchSingleTop + restoreState`로 탭별 상태를 보존한다.
- 인셋: 바깥 `Scaffold`의 innerPadding을 NavHost에 `padding` + `consumeWindowInsets`로 적용해, 안쪽 화면이 자기 Scaffold를 열어도 상태바·내비바 인셋이 두 번 들어가지 않는다(리뷰 경고 1). `MainActivity`는 `enableEdgeToEdge()` 뒤 `AppNavigation()`만 띄운다. 기존 `PlaceholderScreen`은 삭제.
- 자리 표시 문구는 "…을 준비하고 있어요"로 바꿨다(리뷰 질문 2: 개발 일정 용어 노출 제거).
- `NavDestination.hierarchy`는 라이브러리 확장을 쓴다(리뷰 경고 7).
- 자리 표시 화면 3개(`ui/home/HomeScreen`, `ui/analysis/AnalysisScreen`, `ui/settings/SettingsScreen`)는 각 단계에서 교체된다. 문구는 `strings.xml`.
- `material3`에 아이콘이 없어 `androidx.compose.material:material-icons-core 1.7.8`을 추가했다(BOM 관리 종료, 버전 명시).
