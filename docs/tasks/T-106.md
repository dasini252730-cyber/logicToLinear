### 쉽게 말하면

이 앱의 모든 데이터(책, 글귀, 토론, 분석)를 폰에 저장할 SQLite 데이터베이스를 Room으로 만든다. 시간·날짜·책 상태 같은 특수 타입을 DB에 저장할 수 있게 변환기를 붙이고, DB 스키마를 JSON으로 보관해 나중에 버전 관리할 수 있게 한다.

### 요구사항 원문에서

- `데이터 모델`: 테이블 4개(Book·Quote·Discussion·Analysis)의 필드와 타입 정의 → 엔티티 구현의 기초
- `백업`: "JSON 최상위에 schemaVersion 정수를 두고, DB 마이그레이션과 함께 올린다" → exportSchema 활성화와 version 관리의 필요성
- 기술 스택 "Room": "exportSchema = true, schemas/ 디렉터리를 커밋한다" → 구체적 요구사항
- 기술 스택 "Room": "Instant·LocalDate·enum은 TypeConverter. 시간은 Instant, 완독일만 LocalDate" → 타입별 변환 방식

### 주의할 점

- android.md: `fallbackToDestructiveMigration`은 **사용하지 않음**. 버전 1이므로 마이그레이션은 없지만, 나중의 스키마 변경을 대비한 규칙.
- Instant vs LocalDate: 모든 시간은 Instant (createdAt, lastQuoteAt, startedAt, endedAt, runAt), 완독일(finishedAt)만 LocalDate 사용.
- BookStatus enum: WANT / READING / DONE 세 가지 상태를 TypeConverter로 저장.
- exportSchema = true 필수: 프로젝트의 schemas/ 디렉터리에 스키마 JSON이 생성되어야 하고, 이를 커밋해야 함.

### 완료 조건 체크 방법

- 앱 실행 시 DB 생성: `logcat` 또는 Device File Explorer에서 `/data/data/com.logiclinear.reading/databases/reading.db` 확인
- schemas/1.json 생성: `./gradlew build` 후 `ls app/schemas/1.json` 또는 IDE의 Project 탭에서 확인
- Converter 테스트: `./gradlew test` 실행해 TypeConverter 관련 테스트 통과 확인

## 작업 메모

(2026-10-05) T-103~T-105와 함께 구현.

- `AppDatabase`(version = `DB_SCHEMA_VERSION` = 1, exportSchema = true), 엔티티 4개, DAO 4개. `build(context)`는 `Room.databaseBuilder`만 쓰고 `fallbackToDestructiveMigration`은 없다. 파일명 `reading-log.db`.
- `DB_SCHEMA_VERSION`은 최상위 `const val`로 두어 백업 JSON(T-502)의 schemaVersion이 같은 상수를 참조하게 했다.
- `Converters`: Instant↔epoch 밀리초(Long), LocalDate↔ISO 문자열, BookStatus↔name. 저장 형식을 바꾸면 Migration 필요.
- 스키마 JSON은 `androidx.room` Gradle 플러그인의 `schemaDirectory("$projectDir/schemas")`로 `app/schemas/com.logiclinear.reading.data.db.AppDatabase/1.json`에 생성되어 커밋한다(브리핑의 `schemas/1.json`은 이 경로를 뜻한다).
- 테스트: `ConvertersTest` 6개(왕복, null, 모르는 enum 예외), `AppDatabaseTest` 8개. 모두 통과. 실행 명령은 hook과 같은 `./gradlew testDebugUnitTest`.
- 완료 조건 "앱 실행 시 DB가 생성된다"는 AppContainer(T-107)에서 `AppDatabase.build`를 호출해야 실제로 일어난다. 이 task에서는 in-memory DB로 스키마 생성이 되는 것까지 확인했다.
