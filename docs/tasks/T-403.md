책 상세에 글귀를 최신순으로 나열한다(텍스트, p.번호, 날짜). DONE 책은 별점과 한 줄 소감, 완독일을 상단에 보여준다.

## 작업 브리핑

(2026-10-05, task-briefer 작성)

### 쉽게 말하면
책 상세 화면의 표지·정보 아래에 두 섹션을 추가한다. DONE 책이면 상단에 별점·한 줄 소감·완독일을 보여주고, 그 아래 글귀를 최신 저장순(역시간순)으로 나열해 텍스트, 페이지 번호(있으면), 저장 날짜를 표시한다. READING이나 WANT 책은 글귀 목록만 보인다.

### 요구사항 원문에서
- `화면과 사용자 흐름 > 책 상세`: "책 상세에서 ... 글귀 목록, 별점·한 줄, 토론 목록, 완독 처리 버튼" 표시 — 화면 구성 개요
- `기능 상세 > 글귀 OCR과 문장 선택`: "저장 단위는 '이번 촬영에서 선택한 전체'가 Quote 1건이다." 및 "선택 결과를 저장 전에 편집 가능한 텍스트 칸으로 보여준다." — Quote 단위 표시와 페이지 필드(null 가능)

### 주의할 점
- Quote.page는 Int?로 nullable이다. page가 null인 글귀는 "p.123" 형태가 아니라 "페이지 번호 없음" 같은 안내나 아무것도 표시하지 않아야 한다.
- 글귀 목록은 역시간순(최신순)이어야 한다(Quote.createdAt 내림차순).
- Quote 텍스트는 길 수 있으므로 maxLines 제한이나 "더 보기" 펼치기를 고려한다(요구사항에는 명시 없음).
- BookDetailViewModel의 uiState에 quotes: Flow<List<Quote>>를 추가하고, BookDetailScreen에서 collectAsStateWithLifecycle()로 수집한다.

### 완료 조건 체크 방법
- 책 상세를 열었을 때 DONE 책에는 별점(별 모양 또는 숫자)과 한 줄 소감, 완독일이 보이는지 확인
- READING 또는 WANT 책에는 별점·소감·완독일이 보이지 않고 글귀 목록만 보이는지 확인
- 글귀 목록에 텍스트, 페이지 번호(있으면), 저장 날짜가 표시되는지 확인
- page가 null인 글귀가 "p." 없이 표시되는지 확인
- 새 글귀를 저장한 후 상세 화면을 새로고침(또는 navigate away/back)했을 때 새 글귀가 목록에 나타나는지 확인
