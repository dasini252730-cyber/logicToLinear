## 설명

READING 책이 없으면 셔터를 비활성화하고 '읽는 중인 책을 먼저 등록하세요' 버튼으로 서재로 보낸다. OCR이 텍스트를 하나도 못 읽으면 '글자를 찾지 못했어요. 더 밝은 곳에서 다시 찍어 주세요' + 다시 찍기 버튼.
