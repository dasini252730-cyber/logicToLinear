### 쉽게 말하면
READING 책이 하나도 없으면 카메라 셔터가 눌리지 않도록 비활성화하고, 대신 사용자에게 "읽는 중인 책을 먼저 등록하세요"라는 버튼을 보여줘서 서재로 보낸다. 또한 OCR이 텍스트를 하나도 못 읽었을 때는 "글자를 찾지 못했어요. 더 밝은 곳에서 다시 찍어 주세요"라고 알려주고 다시 찍기 버튼으로 다시 시도할 수 있게 한다.

### 요구사항 원문에서
- `예외 처리 > READING 책이 하나도 없는데 촬영`: "셔터 비활성, '읽는 중인 책을 먼저 등록하세요' 버튼 → 서재로 이동" — 책 없음 상황을 감지하면 UI에서 셔터를 비활성하고 안내 문구와 함께 서재 화면으로 가는 버튼을 보인다
- `예외 처리 > OCR이 텍스트를 하나도 못 읽음`: "'글자를 찾지 못했어요. 더 밝은 곳에서 다시 찍어 주세요' + 다시 찍기 버튼" — OCR 결과가 비어있으면 다이얼로그로 안내 메시지를 보이고, 사용자가 다시 촬영할 수 있게 한다

### 주의할 점
- HomeScreen의 125줄 BookBanner는 현재 `state.selectedBook?.title ?: stringResource(R.string.home_no_reading_book)`로 이미 텍스트는 표시하고 있음. 이 task에서는 텍스트만 보이고 버튼 동작(서재로 이동)을 추가해야 한다
- HomeViewModel의 51줄 capture() 함수에서 이미 `val book = uiState.value.selectedBook ?: return`로 null 체크가 있음. 다만 상태 업데이트로 UI에 reflected되는지 확인 필요
- Shutter의 110~115줄에서 이미 `enabled = state.selectedBook != null && !state.capturing` 조건이 있으므로 셔터 비활성화는 구현됨. 시각적 피드백(색상 변경 등)은 현재 코드(153줄)에서 `if (enabled)` 분기로 이미 처리됨
- OCR 에러 다이얼로그는 118~122줄에서 이미 표시 로직이 있음. 요구사항 문구와 정확히 일치하는지 strings.xml 확인 필요

### 완료 조건 체크 방법
1. READING 책을 모두 삭제한 후 카메라 화면을 열면 상단에 "읽는 중인 책이 없어요" 텍스트가 보인다
2. 그 텍스트를 탭하면 서재(LibraryRoute) 화면으로 이동한다
3. 셔터 버튼이 시각적으로 비활성(회색/흐린 상태)으로 보인다
4. 셔터를 눌렀을 때 아무 동작도 하지 않는다
5. OCR 결과가 빈 경우 OcrRecognizer.recognize() 에서 result.isEmpty가 true가 되고, 다이얼로그에 "글자를 찾지 못했어요. 더 밝은 곳에서 다시 찍어 주세요"가 표시된다
6. "다시 찍기" 버튼을 누르면 다이얼로그가 닫히고 카메라 화면으로 돌아와 다시 촬영할 수 있다

## 작업 메모

(2026-10-05)

- READING 책 없음: `HomeUiState.noReadingBook`(책 목록을 받았고 READING이 0개)이면 상단 배너가 "읽는 중인 책을 먼저 등록하세요" 버튼이 되고 `navigateTopLevel(LIBRARY)`로 서재 탭에 간다. 셔터는 `canCapture`(선택 책 있음 && 촬영 중 아님)가 false라 눌리지 않고 회색 원으로 보인다. `HomeViewModel.capture()`도 선택 책이 없으면 바로 반환한다.
- OCR 빈 결과: `OcrResult.isEmpty`면 `ocrEmpty = true` → `ErrorDialog`에 요구사항 원문 "글자를 찾지 못했어요. 더 밝은 곳에서 다시 찍어 주세요" + 버튼 "다시 찍기". 닫으면 카메라 화면 그대로라 바로 재촬영한다. 문장 선택 화면으로 넘어가지 않는다(`recognized`는 결과가 있을 때만 true).
- 촬영 자체 실패(카메라 오류)는 별도 문구 "촬영에 실패했어요: …" + 같은 "다시 찍기" 버튼.
- 테스트 `HomeViewModelTest.READING_책이_없으면_셔터_불가_안내_상태`. OCR 빈 결과 분기는 ML Kit가 JVM에서 돌지 않아 코드 검토와 T-212 실기기로 확인한다.
