### 주의할 점

- **minSdk 26 고정**: 요구사항에서 "26 이상 권장"이지만 T-101에서는 26으로 확정해야 한다. 나중에 올리려면 migration task가 필요하다.
- **Gradle 래퍼 필수**: 환경에 전역 Gradle 설치가 없으므로 gradlew/gradlew.bat와 gradle/wrapper/ 안에 wrapper jar가 반드시 있어야 한다. `gradle wrapper` 명령이나 Android Studio 프로젝트 생성 마법사로 생성해야 한다.
- **JDK 경로**: JAVA_HOME이 Android Studio의 JBR(JDK 21 계열)을 가리켜야 한다. 빌드 중 JAVA_HOME_21_X64 같은 환경 변수도 확인할 수 있다.
- **패키지명**: com.example.bookapp으로 확정하되, 사용자가 나중에 앱 배포 시 변경할 여지를 두도록 Gradle 변수로 parameterize할 수도 있다 (지금은 하드코딩해도 됨).
- **라이브러리 버전**: Compose, Room 등의 정확한 버전은 구현 당시 공식 문서(Android Developers)로 확인하고, 프롬프트 캐싱이 필요하면 Anthropic 공식 가격표도 확인.
- **.gitignore**: build/, local.properties, *.keystore를 반드시 제외해야 한다. 기존 .gitignore와 merge하되 중복 제거.

### 완료 조건 체크 방법

- `./gradlew assembleDebug` 또는 `gradlew.bat assembleDebug` 실행 → 0 종료 코드 확인
- `gradlew.bat installDebug` (또는 Android Studio 동기화 후 Run) → 실기기 또는 에뮬레이터에 APK 설치 → 빈 Compose 화면(보통 파란색 또는 흰색 배경) 뜸 확인
- `git status` → build/, local.properties, *.keystore가 .gitignore에 나열되어 있고, `git add .`해도 tracking되지 않음 확인
