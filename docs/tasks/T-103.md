## 작업 브리핑

### 쉽게 말하면
Book 엔티티는 앱의 핵심 테이블로, 사용자가 등록한 책의 제목, 저자, 상태(읽고 싶음/읽는 중/다 읽음), 별점 등을 저장합니다. 이 작업은 Room을 사용해 안드로이드 로컬 DB에 Book 테이블의 구조를 정의하고, 책을 상태별로 조회하거나 최근에 읽던 책을 빠르게 찾는 쿼리를 DAO에 추가합니다.

### 요구사항 원문에서
- `데이터 모델 > Book`: Book 테이블 필드 14개 (id, title, author, publisher, isbn13, coverUrl, category, description, status, rating, oneLiner, finishedAt, createdAt, lastQuoteAt) — 엔티티의 필드명, 타입, null 여부를 결정하는 정의서
- `책 상태 전이`: "WANT → READING: 책 상세에서 '읽기 시작' 버튼", "READING → DONE: 완독 처리 흐름", "DONE → READING: '다시 읽기' 버튼", "카메라 홈의 책 선택 목록에는 READING 책만 보임" — BookStatus enum의 값(WANT/READING/DONE)과 DAO 쿼리(observeByStatus)의 근거
- `.claude/rules/android.md` Room 규칙: "Instant·LocalDate·enum은 TypeConverter", "`exportSchema = true`, `schemas/` 디렉터리를 커밋" — TypeConverter 구현과 Room Database 설정 방식
- `.claude/code-limits.json`: "*Dao.kt 120줄 상한" — BookDao.kt의 최대 길이 제약

### 선행 작업이 남긴 것
- T-102 (예정): 핵심 의존성(Room ksp, Compose Navigation, kotlinx.serialization 등) 추가 및 빌드 확인. T-103은 T-102가 완료된 후 Room 의존성을 사용합니다.

### 주의할 점
- **Room schema 커밋**: `exportSchema = true`로 설정하고 `schemas/` 디렉터리(초기 schema JSON 파일)를 같은 커밋에서 추가해야 합니다.
- **TypeConverter 위치**: Instant와 LocalDate에 대한 TypeConverter 클래스를 data/db 패키지에 정의합니다 (별도 파일 또는 Book.kt 내부).
- **enum BookStatus의 Room 인식**: `status` 필드가 enum인 경우, Room이 자동으로 String으로 변환하도록 설정하거나 TypeConverter를 별도 작성합니다. 요구사항에는 enum이라 명시되었지만 Room 적용 방식을 확인하세요.
- **observeByStatus 반환형**: Flow<List<Book>>이므로 쿼리가 @Query("SELECT * FROM book WHERE status = ?1") 형태여야 합니다.
- **latestReadingByQuote 쿼리**: "lastQuoteAt 기준 최근 READING 책 조회"는 `SELECT * FROM book WHERE status = 'READING' ORDER BY lastQuoteAt DESC LIMIT 1`로 구현할 것으로 예상. 첫 화면에서 기본 선택 책 결정에 사용됩니다.
