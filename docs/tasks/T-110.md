## 설명

제목(필수)·저자(선택)만 받아 등록한다. 상태 기본값 READING, 변경 가능. 제목+저자가 같은 책이 있으면 경고만 하고 등록은 허용한다.

## 작업 브리핑

### 쉽게 말하면

사용자가 책 검색에 실패했거나 원하지 않을 때, 서재의 "+" 버튼에서 제목과 저자만 직접 입력해서 책을 등록하는 화면을 만든다. 제목은 반드시 입력해야 하고, 같은 제목과 저자를 가진 책이 이미 있으면 경고만 표시하고 저장할 수 있게 한다.

### 요구사항 원문에서

- 흐름 2: 책 등록 "결과 없음 또는 오프라인 → \"직접 입력\" 버튼 → 제목·저자만 받아 등록" — 이 task에서 구현할 직접 입력 폼의 동작
- 책 검색 "같은 isbn13이 이미 있으면 \"이미 서재에 있어요\"로 막는다. 직접 입력 책은 제목+저자가 같으면 경고만 한다" — 중복 책에 대한 처리 방침
- 제품 원칙 "사용자 노출 문구는 요구사항 원문 그대로 써야 한다" — 오류 메시지와 안내 문구는 정확히 일치해야 함

### 주의할 점

- 제목은 필수 입력이므로 공백만으로는 저장 불가. 앞뒤 공백은 자동 제거.
- 중복 확인은 제목+저자 조합이 같은 기존 책이 있는지 확인. 저자가 없으면 (null·공백)도 포함해서 비교.
- 상태 기본값 READING이지만 사용자가 변경 가능 (WANT, READING, DONE 중 선택).
- 저장 후 LibraryScreen의 리스트가 즉시 업데이트되어야 하므로, ViewModel에서 관찰 가능(Observable/Flow) 데이터를 사용.
- T-109 서재 화면이 먼저 완료되어야 네비게이션 구조가 명확하므로, 이 task는 T-109 이후에 시작하는 것이 순서.

### 완료 조건 체크 방법

- 제목 없이 저장 불가: 제목 입력 칸을 비우고 저장 버튼을 눌렀을 때 오류 메시지 또는 버튼 비활성 확인
- 중복 제목+저자 시 경고 표시: 기존 책과 같은 제목·저자로 등록 시도 시 경고 다이얼로그 표시, 그 후 "확인" 누르면 저장 진행 확인
- 저장 후 서재 목록 반영: 책 등록 후 서재 화면으로 돌아가 해당 상태 탭에서 새로 등록한 책이 목록에 보이는지 확인
