### 쉽게 말하면
Claude API에서 제공하는 가장 저렴한(Haiku) 모델과 중급(Sonnet) 모델의 현재 정확한 모델 ID, 입출력 토큰 단가, 프롬프트 캐싱 단가를 공식 문서에서 확인해 기록한다. 이 정보는 앱의 기본 모델을 정하고 사용자가 예상 비용을 이해하는 데 필요하다.

- `AI 기능 / 비용 통제`: "모델 기본값은 Haiku 계열. 설정에서 Sonnet으로 바꿀 수 있게 한다." — 앱 설정 화면에서 선택 가능한 두 모델의 단가가 필요함

### 주의할 점
- 공식 가격 페이지(claude.com/pricing)의 정보는 1M 토큰 단위이고, 실제 API 호출에서는 이 단가를 기준으로 청구된다.
- 프롬프트 캐싱 단가는 "읽기(재사용) 비용"과 "쓰기(저장) 비용"이 다르므로, 두 가지를 모두 기록해야 한다.
- 토론과 분석의 시나리오가 다르므로 각각의 예상 토큰 사용량과 비용을 따로 계산한다.
- 이 task는 정보만 수집·기록하고, 실제 코드에 상수를 정의하는 작업은 T-601(또는 다음 단계)에서 한다.

### 완료 조건 체크 방법
- `claude.com/pricing` 페이지에서 Haiku 4.5와 Sonnet 5의 모델 ID, 입력/출력 단가 캡처 완료 확인
- Prompt caching의 읽기/쓰기 단가 기록 완료 확인
- 토론 1턴(질문/답변 1쌍, 최대 400 토큰)의 예상 비용 계산식과 결과 기록 확인
- 분석 1회(2000 토큰 상한)의 예상 비용 계산식과 결과 기록 확인
