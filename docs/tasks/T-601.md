### 주의할 점
- cache_control 블록은 system 메시지 중 책 컨텍스트에만 붙는다(토론). 분석 호출에는 붙지 않는다.
- 재시도는 자동 1회만. 사용자가 "재시도" 버튼을 누르는 것은 새로운 호출이다.
- 401(UNAUTHORIZED)은 API 키 오류. 사용자 메시지 "설정에서 API 키를 확인하세요"로 매핑해 설정 화면 링크를 제공한다.
- 429(TOO_MANY_REQUESTS)는 할당량 초과. 사용자 메시지 "API 호출 한도를 초과했습니다"
- 5xx 서버 오류와 네트워크(타임아웃, DNS) 오류는 "네트워크 오류가 발생했습니다. 잠시 후 다시 시도해 주세요" 로 통일

## 작업 메모

(2026-10-05)

- `data/remote/anthropic/AnthropicApi`: `POST v1/messages`, 헤더 `x-api-key`(호출마다 SecretStore에서), `anthropic-version: 2023-06-01`. DTO `MessagesRequest(model, max_tokens, system: List<SystemBlock>, messages, thinking?)`, `SystemBlock(text, type="text", cache_control?)`, `ChatMessage(role, content)`, 응답 `MessagesResponse(content[], stop_reason, usage)`. `anthropicJson`은 `explicitNulls=false`라 cache_control·thinking이 null이면 키 자체를 보내지 않는다.
- `AnthropicClient(api, secretStore, modelProvider, onCall, retryDelayMs)` : `AiChat.complete(AiRequest(system, messages, maxTokens))`. 결과 `AiResult` = Success(text, usage, stopReason) / NoKey / InvalidKey(401) / RateLimited(429) / ServerError(5xx·529) / Network(IOException·직렬화) / Rejected(그 외 4xx + 서버 메시지).
- 자동 재시도: Network·ServerError·RateLimited만 1.5초 뒤 1회. 401·4xx는 재시도 없음. 호출 카운터(`onCall`)는 사용자 동작 1회당 1번, 재시도는 세지 않는다.
- T-003 반영: Sonnet 5 선택 시 `thinking: {"type":"disabled"}`를 명시(생략하면 adaptive thinking이 켜져 사고 토큰 과금), temperature 등 샘플링 파라미터는 보내지 않는다. Haiku는 thinking 생략.
- 타임아웃 connect 10초 / read 60초 / call 90초(분석 2000 토큰 응답 고려). 로깅 인터셉터 없음(키·글귀 노출 방지).
- `AppContainer.aiChat`: 모델은 `appPreferences.model`, 호출마다 `appPreferences.recordCall(YearMonth.now())`.
- 모델 ID는 `AiModel`(claude-haiku-4-5 / claude-sonnet-5, T-003). 사용자 키 발급(T-002) 뒤 콘솔에서 재확인 필요.
