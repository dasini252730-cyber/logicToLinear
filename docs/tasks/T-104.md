## 작업 브리핑

2026-10-05 · task-briefer

### 쉽게 말하면

사용자가 책을 읽으며 OCR로 추출한 문장들을 저장하는 Quote(글귀) 엔티티와 쿼리 메서드들을 만든다. 각 글귀는 어느 책에서 나온 것인지 기록하고, 책을 삭제하면 그 책의 글귀도 모두 함께 삭제된다.

### 요구사항 원문에서

- `데이터 모델 > Quote`: "id (Long PK), bookId (Long FK) - Book 삭제 시 함께 삭제, text (String) - 사용자가 선택한 문장(들), page (Int?) - OCR 인식 또는 직접 입력, createdAt (Instant)" — Quote 엔티티의 구조와 외래키 관계 정의
- `삭제`: "책 삭제는 상세 메뉴에서 확인 다이얼로그 후 삭제. 글귀·토론도 함께 삭제된다." — Room CASCADE 설정으로 구현되는 관계
- `화면과 사용자 흐름 > 흐름 1`: "저장 → 카메라 화면으로 복귀, 토스트 '저장됨 (p.123)'. 사진은 메모리에서 폐기." — Quote가 저장되는 시점과 저장 내용

### 주의할 점

- Room의 `onDelete = ForeignKey.CASCADE` 속성으로 Book 삭제 시 자동으로 해당 Quote가 모두 삭제되도록 설정해야 함
- Instant 필드는 TypeConverter 필요 (요구사항에서 "createdAt (Instant)" 명시)
- observeByBook은 Flow를 반환하는 쿼리 (@Query + @kotlin.coroutines)
- 테스트에서 Book 삭제 시 CASCADE 동작 확인 필요
