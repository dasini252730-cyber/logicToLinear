### 쉽게 말하면

OCR 결과에서 이미지 상단 15% 또는 하단 15% 영역에 있는 숫자들을 페이지 번호 후보로 추출하는 순수 함수를 만듭니다. 숫자는 1~4자리만 유효하며, 중간의 다른 텍스트는 무시합니다. 단위 테스트로 여러 경우를 검증합니다.

### 요구사항 원문에서

- `페이지 번호 자동 인식`: "이미지 상단 15% 또는 하단 15% 영역에 있는 Line 중 숫자만으로 된 1~4자리 텍스트를 페이지 후보로 본다." — 후보 추출 위치와 자릿수 범위
- `페이지 번호 자동 인식`: "후보가 1개면 자동 채움. 2개 이상이면 비워 두고 후보를 칩으로 보여줘 탭 선택." — 후보 개수에 따른 UI 동작 (T-208)
- `페이지 번호 자동 인식`: "사용자가 직접 입력한 값이 우선한다." — 직접 입력이 후보를 덮음 (T-208)

### 주의할 점

- 위치 판정: 이미지 높이의 0~15%가 상단, 85~100%가 하단. ML Kit Line 객체의 좌표 계산 필요
- 숫자만 추출: 정규식 `^\d{1,4}$`로 숫자만 된 1~4자리 판정. 공백이나 다른 문자 포함 시 제외
- 중앙 제외: 이미지 중간(15~85%)에 있는 숫자는 후보가 아님
- 5자리 이상 제외: "1234" OK, "12345" NG
- 경계값 테스트 필수:
  - 후보 0개 (숫자 없음)
  - 후보 1개 (자동 채움)
  - 후보 2개 이상 (칩 선택)
  - 상단 정확히 15% 경계
  - 하단 정확히 85% 경계
  - 4자리·5자리 구분
- 입력 정보: T-204의 SelectionScreen에서 선택된 줄은 사용 안 함. T-203의 원본 Line 목록을 사용
- T-208과의 연계: extractPageCandidates() 결과 List<String>을 QuoteEditViewModel에 전달해서 UI 제어
