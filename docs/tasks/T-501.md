### 쉽게 말하면
앱의 설정 화면을 만드는데, 사용자가 두 개의 API 키(알라딘 TTB, Anthropic)를 입력할 수 있는 텍스트 칸과 AI 모델을 선택하는 버튼을 추가한다. 입력된 키는 암호화되어 저장되고, 모델은 기본값 Haiku(저렴)에서 Sonnet(더 정확)으로 변경할 수 있다.

### 요구사항 원문에서
- `화면과 사용자 흐름 > 설정`: "API 키 입력, JSON 내보내기/가져오기" — 이 task에서 키 입력 부분을 구현
- `AI 기능 > 비용 통제`: "모델 기본값은 Haiku 계열. 설정에서 Sonnet으로 바꿀 수 있게 한다." — 모델 선택 UI와 저장 기능의 요구사항
- `기술 스택`: "API 키는 앱 설정 화면에서 사용자가 직접 입력해 EncryptedSharedPreferences에 저장한다." — SecretStore(T-302)와의 통합 방식
- `기술 스택 / AI`: "모델 claude-haiku-4-5 기본, claude-sonnet-5 선택" — T-003에서 확정된 모델 ID 상수

### 선행 작업이 남긴 것

- T-108: 하단 탭 네비게이션과 SettingsScreen이 라우트에 등록되어 있음

### 주의할 점
- **모델 선택값은 비밀이 아님**: SecretStore가 아닌 일반 SharedPreferences(기존) 또는 DataStore Preferences(1.2.1 이미 의존)로 둘 수 있다. 요구사항에서는 "이번 달 호출 횟수" 같은 비밀 아닌 설정을 어느 저장소에 둘지 명시하지 않았으므로, 프로젝트 패턴을 따라 DataStore 또는 SharedPreferences를 선택.
- **API 키 입력 필드는 마스킹(password = true)을 해야 함**.
- **저장 버튼을 눌렀을 때**: SecretStore에 저장하고, 성공/실패 토스트를 보여준다. 요구사항에는 "설정 화면"이 어떤 흐름을 쓸지는 명시되지 않았으므로, 같은 화면 내 저장·조회 패턴이나 다이얼로그를 쓸 수 있다. T-302에서 임시 입력 다이얼로그를 두었다면 그것을 활용.

### 완료 조건 체크 방법
- 앱을 실행해 설정 탭으로 이동, TTB 키와 Anthropic 키를 입력 후 저장 버튼 누르기
- 앱을 완전히 종료했다 다시 시작했을 때 저장한 키가 여전히 표시되는지 확인 (마스킹된 상태여도 가능)
- 모델 선택 UI(라디오 버튼/드롭다운/탭)에서 Haiku → Sonnet으로 변경, 앱 재시작 후 기본값이 Sonnet으로 유지되는지 확인
- SharedPreferences 파일 또는 DataStore를 확인해 키가 암호화되고 모델 선택값이 저장되었는지 확인
