## 설명

DONE 책 3권 미만 또는 글귀 10개 미만이면 버튼 비활성 + '책 N권, 글귀 M개 더 필요해요' 안내. 조건 충족 시 버튼 탭 → 호출 → Analysis 저장. 키 미입력 시 설정으로 안내.

## 작업 브리핑

(2026-10-05, task-briefer 작성)

### 쉽게 말하면
분석·추천 화면의 중심 부분을 만든다. 사용자가 DONE 책을 3권 이상, 글귀를 10개 이상 남겼을 때만 "분석하기" 버튼을 활성화한다. 버튼을 누르면 Claude를 호출해 분석 결과를 받고 DB에 저장한다. API 키가 없으면 설정 화면으로 안내한다.

### 요구사항 원문에서
- `흐름 4: 분석·추천`: "1. 분석 탭. DONE 책 3권 미만 또는 글귀 10개 미만이면 버튼 비활성 + 남은 수 안내. / 2. 버튼 탭 → Claude API 호출 → 취향 해석 글 + 추천 책 목록 표시. / 3. 추천 카드의 '읽고 싶음에 담기' 탭 → WANT 상태로 Book 생성." — 흐름의 1-2단계
- `예외 처리`: "Anthropic 키 미입력 상태에서 분석·토론 시도 → 설정 화면으로 안내" — 401 또는 NoKey 오류 처리
- `AI 기능 > 비용 통제`: "호출은 항상 사용자 동작(버튼, 전송)으로만 시작한다" — 수동 버튼 호출만

### 주의할 점
- "책 N권, 글귀 M개 더 필요해요" 안내: DONE 책이 2권이고 글귀가 8개면 "책 1권, 글귀 2개 더 필요해요" 표시. 요구사항 "예외 처리" 표에는 없지만 "흐름 4" 명시.
- 로딩 중 버튼 비활성: 호출이 진행 중이면 버튼을 눌러도 반응 없게 (다중 호출 방지, T-609와 동일)
- API 키 미입력(또는 빈 문자열): SecretStore.isSet(ANTHROPIC_API) == false. 이 경우 설정 화면으로 이동 (라우팅은 ViewModel 이벤트로 올려서 Screen에서 처리)
- Analysis 저장: T-602의 inputBookCount, inputQuoteCount를 함께 저장. 이는 UI가 아니라 로직(buildAnalysisInput)에서 제공한 값
- 호출 카운터: AppPreferences.recordCall(YearMonth.now()) 호출. 성공·실패 무관? 요구사항 "비용 통제": "호출 1회 기록"이므로 API 요청이 나간 후에만 카운트 (실패해도 카운트)

## 작업 메모

(2026-10-05)

- `domain/AnalysisReadiness(doneBooks, quotes)`: 상수 `ANALYSIS_MIN_BOOKS=3`, `ANALYSIS_MIN_QUOTES=10`, `missingBooks/missingQuotes/ready`. 화면 문구는 "책 N권, 글귀 M개 더 필요해요"를 부족한 쪽만 조합한다(둘 다 부족하면 둘 다, 하나면 하나).
- `data/repo/AnalysisRepository`: `observeReadiness()`(DONE 책 flow + 글귀 수 flow), `observeAll()`, `run()` = 전체 수집(`buildAnalysisInput`, 최근 토론 5회 × 마지막 사용자 발언 3개) → `AiChat.complete`(system 1블록, max_tokens 2000) → `parseAnalysis` → `RecommendationEnricher` → Analysis insert. 실패면 `Failed(AiResult.Failure)`, 저장 없음.
- `ui/analysis/AnalysisViewModel`: 버튼 `run()`은 `running`이거나 조건 미달이면 무시(중복 호출 차단). 호출 카운터는 클라이언트(`AppContainer.aiChat`의 onCall)가 올리므로 화면은 신경 쓰지 않는다.
- 키 미입력은 `AiResult.NoKey` → `AiErrorCard`가 "Anthropic API 키를 설정에서 입력하세요" + "설정으로" 버튼(요구사항 "예외 처리": 설정 화면으로 안내).
- 시스템 프롬프트는 `AppContainer`가 `R.raw.prompt_analysis_system`을 호출 시점에 읽어 넘긴다.
