## 작업 브리핑

(2026-10-05, task-briefer 작성)

### 쉽게 말하면
카메라 화면 상단에 현재 읽고 있는 책의 이름을 보여준다. 사용자가 이 제목을 탭하면 READING 상태인 책들의 목록이 시트 형태로 나타나고, 다른 책을 선택하면 그 책이 새 기본값이 된다. 글귀를 저장한 책이 다음 실행 시 자동으로 선택된다.

### 요구사항 원문에서
- `확정된 결정 > 첫 화면`: "카메라, 마지막에 찍던 책이 기본 선택" — 앱을 실행했을 때 가장 최근에 글귀를 저장한 책을 기본으로 보여준다
- `화면과 사용자 흐름 > 카메라(홈)`: "상단에 현재 선택된 책 이름, 탭하면 책 변경" — 상단 배너에 책 제목을 표시하고 인터랙티브하게 만든다
- `흐름 1: 글귀 저장`: "상단에 `lastQuoteAt`이 가장 최근인 READING 책이 표시된다" — UI에서 보여줄 책을 데이터베이스의 lastQuoteAt 필드로 결정한다
- `책 상태 전이`: "카메라 홈의 책 선택 목록에는 READING 책만 보인다" — 선택 시트에서 읽는 중인 책(READING 상태)만 필터링해서 나열한다

### 주의할 점
- BookBanner는 이미 있으므로(125~135줄) 탭을 추가하되 현재 "제목 표시"만 하는 구조는 그대로 둔다
- selectedBook이 null인 경우(READING 책 없음)는 T-210에서 별도 처리하므로, 이 task에서는 책 목록 필터링에만 집중한다
- 시트가 닫힐 때 선택된 책이 없으면 기존 책을 유지해야 한다
- lastQuoteAt 업데이트는 글귀 저장 시 자동이므로 이 task에서는 추가 작업 없다

### 완료 조건 체크 방법
1. 카메라 화면 상단의 책 제목을 탭하면 BottomSheet/Dialog가 뜬다
2. 시트에는 READING 상태인 책들만 (WANT나 DONE 제외) 나열된다
3. 목록에서 다른 책을 선택하면 상단 제목이 바뀐다
4. 앱을 종료했다가 특정 책에서 글귀를 저장한 후 재실행하면, 그 책이 자동으로 선택되어 있다

## 작업 메모

(2026-10-05)

- `HomeViewModel.uiState`는 `observeDefaultReadingBook()`·`observeByStatus(READING)`·로컬 상태를 `combine`한다. `selectedBook = readingBooks.firstOrNull { id == chosenBookId } ?: default`. 사용자가 고른 책이 READING에서 빠지면(완독 등) 자동으로 기본값으로 돌아간다(테스트 `고른_책이_READING에서_빠지면_기본_선택으로_돌아간다`).
- 상단 배너(`BookBanner`)의 제목을 탭하면 `BookPickerSheet`(ModalBottomSheet)가 뜨고 READING 책만 나열한다(요구사항 "책 상태 전이": WANT·DONE 책에 글귀를 남기려면 상태를 바꾼다). 선택 중인 책에 체크 표시.
- 선택은 ViewModel 메모리에만 있다. 글귀를 저장하면 그 책의 lastQuoteAt이 최신이 되어 다음 실행에서도 기본으로 선택되므로 별도 영속화는 하지 않았다(요구사항 "마지막에 찍던 책이 기본 선택").
- 파일 분리: `BookPickerSheet.kt`(68줄), `HomePermission.kt`(63줄, 권한 안내·오류 다이얼로그). `HomeScreen.kt`는 179/250줄.
- 테스트 `HomeViewModelTest` 3개. OCR은 `OcrEngine` 인터페이스로 바꿔 가짜 구현을 넣었다(모킹 라이브러리 미추가).
