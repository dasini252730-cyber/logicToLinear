## 작업 브리핑

(2026-10-05, task-briefer 작성)

### 쉽게 말하면
사용자가 20번 대답하면 토론을 끝낸다. 이때 앱이 Claude에게 "이제 마무리하고 마지막 한마디 해 줄래?"라는 속삭이는 지시를 몰래 붙여서 요청을 보낸다. Claude의 마무리 답변을 받은 뒤 입력창을 닫고, Discussion의 endedAt에 현재 시간을 기록해 "이 토론은 끝났다"고 표시한다.

### 요구사항 원문에서
- `AI 기능 > 완독 후 토론`: "사용자 20턴 도달 시 AI에게 '마무리해 달라'는 숨은 지시를 붙여 마지막 응답을 받고 입력창을 닫는다" — 마무리 지시 및 input 닫기
- `데이터 모델 > Discussion`: "messagesJson: [{role, content, at}] 배열, 최대 40개(20턴)" — 메시지 개수 제한 (사용자 20 + AI 응답 최대 20 = 40)
- `데이터 모델 > Discussion`: "endedAt: Instant?" — 토론 종료 시 기록

### 주의할 점
- 마무리 지시: system 블록 배열에 세 번째 블록으로 추가해야 하나, 아니면 user 메시지에 붙여야 하나? 요구사항은 "숨은 지시"라고만 하므로, T-702에서 생성한 system 블록 2개는 유지하고 system 수정 없이 마지막 user 메시지 앞에 지시를 붙이는 방식이 더 깔끔할 수 있음. 또는 마지막 AiRequest 생성 시만 system에 추가. 구현 시 판단.
- messagesJson 배열 최대 40개: 20턴(사용자 20 + AI 응답 20)을 넘으면 안 되므로, 21번째 사용자 메시지는 DB에 저장하지 않음.
- endedAt은 마지막 AI 응답 후 nowMillis()로 기록.

### 완료 조건 체크 방법
- 테스트: countUserTurns()가 정확히 사용자 메시지 개수만 센다 (AI 메시지는 제외)
- 실제 토론: 20번째 사용자 메시지 후 AI의 마무리 멘트가 오고, 그 후 입력창이 비활성화됨 (UI 테스트)
- 데이터베이스 확인: Discussion.endedAt이 null이 아닌 Instant로 기록됨
