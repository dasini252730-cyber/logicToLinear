### 쉽게 말하면

사용자가 여러 줄을 선택했을 때 이를 하나의 문장으로 합치는 규칙을 구현합니다. 줄 끝이 한글 음절 중간(문장 부호 없음)이면 공백 없이 붙이고, 문장 부호로 끝나면 공백 하나로 잇습니다. 순수 함수로 만들어 단위 테스트로 검증합니다.

### 주의할 점

- 순수 함수로 작성: domain/ 폴더에 배치하고 Repository나 ViewModel과 무관하게 테스트 가능해야 함
- 한국어 음절 판정: 문장 부호(마침표, 쉼표, 느낌표, 물음표, 따옴표, 닫는 괄호 등)와 음절 중간의 구분
- 경계값 테스트 필수:
  - 빈 리스트
  - 줄 1개만
  - 음절 중간에서 끊긴 줄
  - 마침표·쉼표로 끝난 줄
  - 따옴표로 끝난 줄
  - 연속 공백 줄
- UI 미리보기: T-206에서 편집 칸에 표시되므로, 이 단계에서는 함수 동작만 확인
- UI 통합 테스트는 T-206에서 함께 확인
