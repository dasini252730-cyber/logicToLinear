## 설명

추천 카드 버튼으로 WANT 상태 Book을 만든다. 알라딘 정보가 있으면 7개 필드를 채우고, 없으면 제목·저자만의 직접 입력 책으로 만든다. 이미 서재에 있으면 담기 버튼을 숨긴다.

## 작업 브리핑

(2026-10-05, task-briefer 작성)

### 쉽게 말하면
분석 화면의 추천 카드 아래에 있는 "읽고 싶음에 담기" 버튼을 누르면, 그 책을 사용자의 서재 WANT 상태로 추가한다. 알라딘 정보(표지, ISBN, 링크 등)가 있으면 그 정보와 함께 저장하고, 없으면 제목과 저자만으로 간단한 책으로 저장한다. 만약 그 책이 이미 서재에 있으면 버튼을 보여주지 않는다.

### 요구사항 원문에서
- `흐름 4: 분석·추천`: "3. 추천 카드의 '읽고 싶음에 담기' 탭 → WANT 상태로 Book 생성." — 동작 명시
- `예외 처리`: "추천된 책이 알라딘에 없음 → 표지 없이 제목·저자·이유만 표시, 담기는 직접 입력 책으로 생성" — 알라딘 정보 부재 처리
- `데이터 모델 > Book`: "isbn13, coverUrl, ... status WANT / READING / DONE" — 저장 필드
- `책 검색`: "같은 isbn13이 이미 있으면 '이미 서재에 있어요'로 막는다. 직접 입력 책은 제목+저자가 같으면 경고만 한다." — 중복 체크

### 선행 작업이 남긴 것

### 주의할 점
- 7개 필드: title, author, publisher, isbn13, coverUrl, category, description, status=WANT. isbn13, coverUrl, category, description은 null 가능 (알라딘 미검색 책)
- 중복 체크: isbn13이 있으면 그것으로 먼저 찾기 → 있으면 버튼 숨기기 / isbn13이 null이면 제목+저자로 찾기 → 있으면 경고 메시지 ("이미 서재에 있어요") 그리고 버튼 숨기기
- "이미 서재에 있어요" 문구: 요구사항 "예외 처리" 표 정확히 인용
- 버튼 상태: isbn13 != null && findByIsbn13() 성공 → 버튼 숨김 / 또는 title+author로 찾기 성공 → 버튼 숨김
- 카드의 onAddToLibrary 콜백: ViewModel 이벤트로 BookRepository.addBook(Book) 호출

### 완료 조건 체크 방법
- `testAddedBookAppearsInLibrary`: "읽고 싶음에 담기" 탭 → 서재 WANT 탭에서 책 보임 (실기기 또는 UI 테스트)
- `testDuplicateBookButtonHidden`: ISBN으로 이미 존재하는 책의 카드에서 버튼이 보이지 않는지 확인
- `testDirectInputBookCreatedWithoutAladin`: coverUrl == null인 추천 카드 담기 → 표지 없이 제목·저자만 저장되는지 확인 (DB 쿼리 확인)
- `testCannotAddSameBookTwice`: 같은 책을 두 번 담으려고 할 때 "이미 서재에 있어요" 메시지 표시 확인
