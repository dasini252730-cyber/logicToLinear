## 작업 메모

(2026-10-05) 사용자 지시("진행 가능한 것은 묻지 말고 계속")에 따라 추천안대로 확정했다. 바꾸고 싶으면 T-301 전에 알려 주면 된다.

**결정: Retrofit 3 + OkHttp 5 + `retrofit2-kotlinx-serialization-converter`**

이유:
- 호출이 두 종류(알라딘 ItemSearch GET, Anthropic Messages POST)뿐이고 모두 단순 JSON이다. Retrofit의 인터페이스 선언 방식이 가장 짧다.
- kotlinx.serialization은 이미 백업 JSON용으로 들어가 있어 컨버터만 추가하면 된다(Moshi·Gson 불필요).
- Anthropic 토론은 매 턴 전체 메시지를 보내는 일반 요청이라 스트리밍이 필요 없다. Ktor의 장점(멀티플랫폼, 스트리밍 DSL)이 쓰이지 않는다.
- 알라딘 `Output=JS` 응답은 비표준일 수 있어 OkHttp 인터셉터에서 본문을 정리한 뒤 컨버터에 넘기기 쉽다.
- MockWebServer(OkHttp)로 기기 없이 클라이언트를 단위 테스트할 수 있다.

적용: T-301에서 의존성 추가. CLAUDE.md 기술 스택 표 HTTP 행 갱신.
