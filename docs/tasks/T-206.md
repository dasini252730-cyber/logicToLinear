## 설명

합쳐진 문장을 편집 가능한 텍스트 칸에 보여준다. 저장하면 Quote를 insert하고 Book.lastQuoteAt을 갱신한 뒤 카메라로 복귀, 토스트 '저장됨 (p.123)'. 이번 촬영 선택 전체가 Quote 1건이다.

### 주의할 점

- DB 갱신 순서: Quote insert + Book.lastQuoteAt 갱신을 트랜잭션으로 처리해야 함 (T-206 범위 내에서 결정)
- lastQuoteAt 필드: 첫 화면(카메라)에서 가장 최근 READING 책을 선택하는 기준이므로 정확히 갱신
- 메모리 해제: 카메라에서 받은 Bitmap은 이 화면 또는 카메라로 돌아갈 때 명시적으로 해제
- 토스트 메시지: "저장됨 (p.123)" 형식에서 123은 페이지 번호 (null이면 "저장됨"만 표시)
- 내비게이션: 저장 후 카메라 화면으로 돌아가야 함 (T-204~T-208은 한 OCR 사이클의 일부)
- 이 작업 후 T-208(페이지 UI)을 합치려면, QuoteEditScreen에 페이지 입력 UI도 함께 배치
- DB 스키마: Book.lastQuoteAt은 이미 있음 (요구사항 "데이터 모델 > Book"), Quote.createdAt도 이미 있음

### 완료 조건 체크 방법

- DB 쿼리로 Quote가 1건 insert되었는지 확인: `SELECT * FROM quote WHERE bookId = ?`
- Book.lastQuoteAt이 저장 시각으로 갱신되었는지 확인: `SELECT lastQuoteAt FROM book WHERE id = ?`
- 카메라 화면이 표시되고 선택 화면이 종료되었는지 UI 테스트
- 토스트 메시지 "저장됨 (p.???)" 또는 "저장됨"이 보이는지 확인
- Bitmap이 메모리에서 해제되었는지 로그 또는 프로파일러로 확인 (가비지 컬렉션 후 메모리 사용량 감소)
