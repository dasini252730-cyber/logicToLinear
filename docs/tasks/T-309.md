## 설명

사용자 결정(2026-10-05): 카카오 대신 국립중앙도서관 소장자료 검색 Open API(GET https://www.nl.go.kr/NL/search/openApi/search.do?key=&kwd=&srchTarget=title&apiType=json&pageNum=1&pageSize=10&category=도서)를 쓴다. 인증키는 관리자 승인(업무일 1~2일) 대기 중. 조사 결과: 오류는 HTTP 200에 {errorCode,errorMsg}로 온다(010 키 없음, 011 유효하지 않은 키, 000·101 서버 오류, 012~015 파라미터 오류). Content-Type은 text/json;charset=UTF-8이라 Retrofit 컨버터 미디어 타입을 맞춰야 한다. 응답 필드는 공식 표상 total·result[]·title_info·author_info·pub_info·pub_year_info·isbn·call_no·type_name·detail_link·kdc_code_1s·kdc_name_1s(실제 JSON 키 표기는 키 승인 후 실호출로 확인). 표지·소개글은 없고 KDC 대분류로 Book.category를 채울 수 있다. KakaoBookApi/KakaoBookClient를 NlBookApi/NlBookClient로 바꾸고 SecretKey.KAKAO_REST→NL_OPENAPI, 설정 문구·추천 링크(detail_link)를 바꾼다.
