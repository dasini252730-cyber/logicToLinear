## 작업 브리핑

(2026-10-05, task-briefer 작성)

### 쉽게 말하면
사용자가 저장된 글귀를 길게 누르면 삭제되고, 화면 하단에 '되돌리기' 버튼이 5초간 표시된다. 버튼을 누르면 원래 글귀가 복구되지만, 5초가 지나가면 DB에서 완전히 사라진다.

### 요구사항 원문에서
- `삭제`: "글귀 삭제는 길게 눌러 삭제, 되돌리기 스낵바 5초." — 글귀 삭제의 기본 동작 정의

### 선행 작업이 남긴 것
- T-403: `ui/book/BookDetailScreen.kt`에 글귀 목록 표시 (길게 누르기 이벤트는 아직)

### 주의할 점
- **FK 제약 조건**: T-404 메모에 따르면 되돌리기 스낵바가 떠 있는 5초 동안 책이 삭제되면 `QuoteDao.insert(saved)`가 `SQLiteConstraintException(FK)`을 던진다. `restore()` 호출 전에 책 존재를 확인하고 없으면 스낵바를 조용히 닫을 것. (현재 `QuoteRepository.restore()`에서 `bookDao.getById()`로 확인하고 false 반환)
- **테스트**: '책 삭제 후 되돌리기' 케이스를 테스트에 추가할 것

### 완료 조건 체크 방법
- 글귀를 길게 눌러 삭제되는지 확인 → 스낵바의 '되돌리기' 버튼 표시 여부 확인
- 되돌리기 버튼 탭 시 글귀가 원래 자리로 돌아오는지 확인
- 5초 대기 후 스낵바 사라지면 DB에서 삭제되었는지 확인 (수동 테스트 또는 단위 테스트)
