## 설명

T-806에서 첫 화면이 서재가 되고 카메라는 책 전용 CaptureRoute뿐이 됐지만 ui/home 패키지·HomeScreen·HomeViewModel·HomeShutter·HomePermission·BookPickerSheet 이름과 홈 전용 로직(chooseBook, observeDefaultReadingBook 기본 책, pickerOpen, noReadingBook 배너)이 남아 있다. 패키지를 ui/capture로, 클래스를 CaptureScreen/CaptureViewModel로 바꾸고, 고정 책만 다루도록 상태를 줄인다. BookPickerSheet와 home_pick_book_* 문자열, lastQuoteAt 기반 observeDefaultReadingBook 사용처를 정리한다. 동작 변경 없음.

### 주의할 점
- **동작 변경 없음**: OCR 흐름, 셔터 비활성 조건(`canCapture`), "읽는 중인 책을 먼저 등록하세요" 안내→뒤로(책 전용 카메라) 또는 →서재(홈 없음) 분기는 그대로 유지.
- **선택기 제거**: chooseBook·openPicker·closePicker 메서드와 pickerOpen·readingBooks·noReadingBook 필드 삭제. HomeUiState.bookLocked와 lockBook만 남기고 고정 책만 다루기.

- **테스트**: 선택기 열기(`openPicker`)·책 선택(`chooseBook`)·기본 책 로직(`observeDefaultReadingBook`) 관련 테스트 제거, 고정 책·셔터·OCR 흐름·권한 테스트만 유지.

## 작업 메모

(2026-10-06)

- `ui/home` → `ui/capture`. `CaptureScreen.kt`(CaptureEntry·CaptureScreen·CaptureActions·BookBanner, 171줄), `CaptureViewModel.kt`(CaptureUiState, 127줄), `CaptureShutter.kt`, `CameraPermission.kt`(옛 HomePermission), `CameraController.kt`(git mv, 패키지만 변경). `BookPickerSheet.kt`와 `home_pick_book_title`·`home_pick_book_selected` 문자열 삭제. `home_register_book_first`는 값은 그대로 두고 키만 `capture_register_book_first`로(리뷰 반영).
- `CaptureViewModel`은 책 id를 생성자로 받는다(Factory가 `createSavedStateHandle().toRoute<CaptureRoute>()`로 읽음, BookDetailViewModel과 같은 패턴). 상태는 `book`(READING일 때만 non-null)·`bookLoaded`·촬영 플래그뿐. `observeById(bookId)` 하나만 구독하고, `observeDefaultReadingBook`·`observeByStatus(READING)` 구독, `chooseBook`·`openPicker`·`closePicker`·`lockBook`·`pickerOpen`·`readingBooks`·`noReadingBook`·`bookLocked`는 모두 사라졌다. `BookRepository.observeDefaultReadingBook`·`BookDao.observeLatestByQuote`는 호출자가 없어 리뷰 뒤 삭제했다.
- 화면은 `CaptureEntry(onRecognized, onBack)` 두 콜백만 받는다(`AppNavigation`에서 `lockedBookId`·`onGoToLibrary` 전달 제거). 배너는 항상 뒤로 버튼 + 제목, 책이 READING이 아니면 "읽는 중인 책을 먼저 등록하세요" 버튼 → 뒤로(상세). 셔터·권한·OCR 흐름·오류 다이얼로그는 그대로.
