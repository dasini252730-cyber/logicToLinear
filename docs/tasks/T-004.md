## 작업 메모

(2026-10-05) 출처: Google Maven 메타데이터(`dl.google.com/dl/android/maven2`)와 ML Kit 공식 문서 `https://developers.google.com/ml-kit/vision/text-recognition/v2/android`.

### 두 가지 배포 방식

| 방식 | Gradle 아티팩트 | 최신 버전 | 모델 위치 | 첫 실행 오프라인 |
| --- | --- | --- | --- | --- |
| **번들(bundled)** | `com.google.mlkit:text-recognition-korean` | 16.0.1 | APK 안에 포함 | **동작한다.** 설치 즉시 사용 가능 |
| 언번들(unbundled) | `com.google.android.gms:play-services-mlkit-text-recognition-korean` | 16.0.1 | Google Play Services가 기기에 다운로드 | 다운로드 전에는 동작하지 않음. 첫 사용 시 대기 가능 |

공식 문서 요지: "bundled (larger app size, faster initialization) / unbundled (smaller app size, dynamic download)". 언번들은 Play Services의 ModuleInstallClient로 설치 시점 다운로드를 요청할 수 있지만 네트워크와 Play Services가 필요하다.

### 결정: 번들 방식

이유:
- 요구사항 `기술 스택 > OCR`의 "온디바이스, 오프라인 동작"과 `설계 원칙`의 "앱을 열면 2초 안에 카메라"를 둘 다 만족하는 쪽은 번들이다. 언번들은 첫 촬영에서 모델 다운로드를 기다리는 경우가 생긴다.
- 1인용 앱이라 APK 크기 증가는 문제가 아니다.
- Play Services 상태에 의존하지 않아 테스트가 결정적이다.

### APK 크기 영향

- `text-recognition-korean-16.0.1.aar` 자체는 1.9 MB(Content-Length 1,899,634). 전이 의존성(`text-recognition-bundled-common` 등)에 모델이 추가로 들어오므로 실제 증가분은 더 크다. 정확한 값은 T-203에서 Android Studio APK Analyzer로 측정해 이 문서에 추가한다. (확인 필요)
- 한국어 인식기는 라틴 문자도 함께 인식한다. 별도 라틴 모델을 추가하지 않는다.

### T-203에 넘길 구현 메모

```kotlin
// app/build.gradle.kts
implementation("com.google.mlkit:text-recognition-korean:16.0.1")

// 사용
val recognizer = TextRecognition.getClient(KoreanTextRecognizerOptions.Builder().build())
val image = InputImage.fromBitmap(bitmap, rotationDegrees)
recognizer.process(image)
    .addOnSuccessListener { text -> text.textBlocks.flatMap { it.lines } }  // Line.text, Line.boundingBox
```

- `Text.TextBlock > Line` 구조 그대로 Line 단위로 나열한다(요구사항 `글귀 OCR과 문장 선택`).
- `Line.boundingBox`의 y 좌표와 이미지 높이로 상단·하단 15% 판정(페이지 번호 후보, T-207).
- minSdk 26은 ML Kit 요구(21 이상)를 충족한다.
- `recognizer.close()`를 화면 종료 시 호출한다.

## 결과

- 결정: **번들 방식**, 아티팩트 `com.google.mlkit:text-recognition-korean:16.0.1`.
- 오프라인 첫 실행: 번들이므로 설치 직후 네트워크 없이 OCR이 동작한다.
- APK 증가분 정확한 측정은 T-203에서 한다.
