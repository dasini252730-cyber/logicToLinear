## 작업 브리핑

(2026-10-05, task-briefer 작성)

### 쉽게 말하면

앱에서 텍스트 인식(OCR)을 할 때 사용할 Google ML Kit 한국어 모델이 앱에 미리 들어가는지, 아니면 첫 사용 시 자동으로 다운로드되는지 확인하는 작업이다. 어떻게 되든 오프라인에서도 작동해야 한다는 점이 중요하고, 어느 방식을 선택하든 앱 설치 파일의 크기와 첫 실행 환경에 영향을 미친다.

### 요구사항 원문에서

- `기술 스택 > OCR`: "Google ML Kit Text Recognition v2 (Korean) | 온디바이스, 무료, 오프라인 동작" — 앱이 선택한 OCR 도구이며 온디바이스 + 오프라인 요구사항이 핵심
- `클로드 코드 작업 순서`: "구현 전 확인할 것: 알라딘 TTB 키 발급, Anthropic 키 발급, 현재 모델명과 단가, **ML Kit 한국어 모델이 번들인지 다운로드 방식인지**." — 구현 전 필수 확인 사항
- `기능 상세 > 글귀 OCR과 문장 선택`: "ML Kit `TextRecognition` Korean 옵션으로 `Text.TextBlock > Line` 구조를 받는다. 화면에는 Line 단위로 나열한다." — T-203에서 사용할 API 구조

### 주의할 점

- 오프라인 첫 실행 요구사항과 배포 방식이 충돌할 수 있다. 번들 방식이면 APK 크기 증가, 다운로드 방식이면 초기 네트워크 의존성 발생 가능.
- 완료 조건 중 "오프라인 첫 실행에서도 OCR이 동작하는지 여부"는 선택한 배포 방식에 따라 명확히 해야 한다. (예: 다운로드 방식 선택 시 "첫 다운로드 후 오프라인"이 기준)
- 이 task는 조사와 기록만 한다. 코드 구현은 T-203에서 한다.

### 완료 조건 체크 방법

- docs/tasks/T-004.md의 "작업 메모" 섹션에 선택한 배포 방식, Gradle 아티팩트명, 버전, APK 크기 영향이 기록되었는가
- "오프라인 첫 실행 여부" 섹션이 명확하게 기록되었는가 (예: "번들 방식이므로 앱 설치 후 오프라인도 즉시 동작" 또는 "다운로드 방식이므로 첫 실행 후 캐시됨")
