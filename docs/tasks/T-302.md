## 설명

TTB 키와 Anthropic 키를 저장·조회하는 SecretStore를 만든다. 설정 화면 UI는 T-501에서 만들고, 여기서는 저장소와 임시 입력 다이얼로그만 둔다.

## 선행 작업

- [T-107 Repository 계층과 수동 DI 컨테이너](T-107.md)

## 완료 조건

- [ ] 키가 평문 SharedPreferences에 남지 않는다
- [ ] 앱 재시작 후에도 키가 유지된다
- [ ] 키가 코드·리소스에 하드코딩되어 있지 않다

## 작업 브리핑

(2026-10-05, task-briefer 작성)

### 쉽게 말하면
앱에 필요한 두 개의 API 키(알라딘 TTB 키, Anthropic 키)를 안전하게 저장하고 불러올 수 있는 저장소를 만든다. 사용자가 설정 화면에서 키를 입력하면, 암호화되어 기기에만 저장되고 코드에는 절대 하드코딩되지 않는다.

### 요구사항 원문에서
- `기술 스택`: "API 키는 앱 설정 화면에서 사용자가 직접 입력해 EncryptedSharedPreferences에 저장한다. 코드에 하드코딩하지 않는다. 1인용 앱이므로 중계 서버는 두지 않는다." — SecretStore 구현의 핵심과 범위
- `기술 스택` (표 네트워크 행): "androidx.security:security-crypto" 선택, 최신 1.1.0 (안정) 사용 — 의존성 지정

### 선행 작업이 남긴 것
- T-107: AppContainer (수동 DI 컨테이너)가 있고, 저장소도 거기에 lazy로 등록된다.

### 관련 파일
| 구분 | 파일 | 이유 | 줄 수 상한 |
| --- | --- | --- | --- |
| 새로 만듦 | app/src/main/java/com/logiclinear/reading/data/secret/SecretStore.kt (예상) | TTB·Anthropic 키 저장·조회 인터페이스와 EncryptedSharedPreferences 구현 | 200 |
| 참고 | app/src/main/java/com/logiclinear/reading/AppContainer.kt | SecretStore를 lazy로 등록하는 패턴 | - |
| 참고 | app/src/main/java/com/logiclinear/reading/ui/settings/SettingsScreen.kt | T-501에서 키 입력 다이얼로그를 붙일 예상 위치(현재는 자리표시) | - |

### 주의할 점
- `EncryptedSharedPreferences.create()`는 MasterKey 또는 `EncryptedSharedPreferences.PrefKeyEncryptionScheme` 설정이 필요하다. 최신 패턴을 확인하라.
- 테스트는 평문 SharedPreferences와 혼동하지 않도록 구분해야 한다.
- "하드코딩하지 않는다"는 요구사항은 키 값을 리소스·상수·BuildConfig에 넣지 않는다는 뜻이다.

### 완료 조건 체크 방법
- 앱 파일시스템에서 SharedPreferences 파일을 열어 키가 암호화되어 있는지 확인 (plaintext 검색 불가)
- 앱 재시작 후 SecretStore.getTtbKey() 등이 저장한 값을 그대로 돌려받는지 확인
- 코드베이스에 grep으로 "ttb", "anthropic" (대소문자 무관), API 키 형태의 문자열이 하드코딩되어 있지 않은지 확인
