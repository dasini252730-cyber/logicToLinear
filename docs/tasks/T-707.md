## 작업 브리핑

(2026-10-05, task-briefer 작성)

### 쉽게 말하면
책 상세 화면의 아래쪽에 그 책과 나눈 토론 목록이 보인다. 각 항목에는 토론을 시작한 날짜, 진행 중인지 종료됐는지 여부, 지금까지의 메시지 수가 표시된다. 토론 항목을 탭하면 토론 채팅 화면으로 이동한다. 또한 완독 저장 직후 나타나는 "이 책에 대해 AI와 이야기해볼까요?" 버튼을 누르면 새 토론이 바로 시작된다.

### 요구사항 원문에서
- `흐름 3: 완독 처리`: "3. 저장 직후 '이 책에 대해 AI와 이야기해볼까요?' 버튼 노출. 탭하면 토론 시작, 아니면 상세로 복귀." — 완독 저장 직후 버튼 동작
- `흐름 5: 완독 후 토론`: "3. 토론은 Discussion에 저장되고 책 상세에서 다시 볼 수 있다." — 토론 목록 표시 위치와 재진입
- `데이터 모델 > Discussion`: "startedAt, endedAt?, messagesJson" — 토론 항목 표시에 필요한 필드

### 선행 작업이 남긴 것
- T-706: DiscussionRepository와 Discussion 저장·조회 완성. DiscussionDao.observeByBook(bookId): Flow<List<Discussion>>
- T-405: BookDetailSections의 DiscussionProposalDialog가 있고, 버튼의 `onTalk()` 콜백이 아직 구현되지 않은 상태

### 주의할 점
- 한 책에 여러 토론을 만들 수 있으므로 토론 목록에는 제목이 없고 (Discussion 엔티티에 제목 필드가 없음) 시작 날짜와 상태·메시지 수만 표시.
- DiscussionProposalDialog의 onTalk 버튼을 누르면: (1) DiscussionRepository.startDiscussion(bookId) 호출 → Discussion 생성 + 첫 질문 요청 → (2) 성공하면 discussionId를 얻어 토론 화면으로 탐색. 실패하면 오류 표시.
- 토론 화면으로의 탐색: nav route에 discussionId를 넘겨서 DiscussionScreen이 id로 Discussion을 로드.

### 완료 조건 체크 방법
- 책 상세 화면에서: 완독 처리 후 "이야기해볼까요?" 버튼 탭 → 토론 화면으로 이동, 첫 질문 표시 확인
- 책 상세 화면 스크롤: 토론 목록 영역에 토론 항목 표시 (시작 날짜, 진행 중/종료 상태, 메시지 수)
- 토론 항목 탭: 해당 토론 화면으로 이동, 이전 메시지 로드 확인
