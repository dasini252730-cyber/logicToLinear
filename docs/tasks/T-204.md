## 작업 브리핑

(2026-10-05, task-briefer 작성)

### 쉽게 말하면

사용자가 촬영한 책 페이지에서 ML Kit OCR이 읽은 텍스트를 줄(Line) 단위로 나열하고, 사용자가 터치해서 선택하거나 해제할 수 있는 화면입니다. 선택된 줄은 강조 표시되며, 자동 필터링은 하지 않습니다.

### 요구사항 원문에서

- `흐름 1: 글귀 저장` (3단계): "문장 선택 화면: 인식된 텍스트를 줄(line) 단위로 나열. 사용자가 원하는 줄을 탭해 선택(복수 가능, 연속 선택 시 하나의 문장으로 합침)." — UI 사양과 선택 범위
- `글귀 OCR과 문장 선택` (구조 설명): "ML Kit `TextRecognition` Korean 옵션으로 `Text.TextBlock > Line` 구조를 받는다. 화면에는 Line 단위로 나열한다." — Line 구조와 화면 표시 방식
- `글귀 OCR과 문장 선택` (필터링): "선택 결과를 저장 전에 편집 가능한 텍스트 칸으로 보여준다." — 필터링 불필요, 사용자가 직접 정제
- `예외 처리` (세로쓰기·표): "OCR 결과가 세로쓰기·표·그림 섞임 → 줄 단위 나열을 그대로 보여주고 사용자가 고른다. 자동 필터링은 하지 않음" — 그대로 나열, 필터링 안 함

### 주의할 점

- 자동 필터링 금지: 세로쓰기나 표가 섞여도 Line 그대로 나열. T-205에서 사용자 선택 후 합치는 단계에서 정제 가능
- 완료 조건 확인: (1) 줄 탭 시 선택/해제 토글, (2) 필터링 없이 모든 줄 표시

- 이 화면은 T-203(OCR)의 결과를 받고, T-205(줄 합치기)로 결과를 보냄. T-206(저장) 전까지는 선택만 가능
