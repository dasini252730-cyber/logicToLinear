## 설명

요구사항의 프롬프트 요지(글귀 중심 해석, 장르 통계 한 문단, 별점 높낮이 차이, 서재 제외 5권 추천 + 한 줄 이유, JSON만 출력)를 실제 프롬프트 텍스트로 작성해 리소스 파일로 관리한다. max_tokens 2000.

## 작업 브리핑

(2026-10-05, task-briefer 작성)

### 쉽게 말하면
Claude에게 사용자의 독서 취향을 분석해 달라는 "지시문"을 작성한다. 이 지시문은 코드에 하드코딩하지 않고 문자열 리소스 파일에 저장해 나중에 쉽게 손볼 수 있게 한다. 지시문은 "글귀를 읽고 이 사람이 뭘 좋아하는지 분석하고, 5권의 새 책을 추천해 달라"는 내용이다.

### 요구사항 원문에서
- `AI 기능 > 취향 분석·추천` 시스템 프롬프트 요지: "저장된 글귀를 핵심 근거로 삼아 '이 사람이 어떤 문장에 멈추는지'를 해석한다. 장르 통계는 보조로 한 문단만. / 별점 높은 책과 낮은 책의 차이를 글귀·소감에서 찾아 말한다. / 아직 안 읽은 책 5권을 추천한다. 이미 서재에 있는 제목(WANT 포함)은 제외한다. 각 추천에 '당신이 저장한 ___ 글귀와 닿아 있어서' 식의 한 줄 이유를 붙인다. / 출력은 JSON만: {\"taste\": \"...\", \"recommendations\": [{\"title\": \"...\", \"author\": \"...\", \"reason\": \"...\"}]}. 마크다운 펜스 없이." — 시스템 프롬프트가 포함해야 할 핵심 지시문
- `ai-api.md`: "max_tokens는 토론 400, 분석 2000" — 분석 호출의 max_tokens

### 주의할 점
- 프롬프트는 XML 문자열 리소스(app/src/main/res/values/analysis_prompt.xml)에 저장. 코드에서 `stringResource(R.string.analysis_system_prompt)` 또는 `context.getString(R.string.analysis_system_prompt)`로 로드.
- JSON 출력 지시: "마크다운 펜스 없이"라는 것은 ```json ... ``` 형태를 쓰지 말고 순수 JSON만 출력하라는 뜻. 이를 프롬프트에 명확히 명시.
- "서재에 있는 제목(WANT 포함) 제외": 프롬프트에 현재 서재의 모든 책 제목(상태 무관)을 "제외 목록"으로 넣는다. 이는 T-602에서 buildAnalysisInput()이 제공해야 한다(기존 코드에 없으면 T-602 범위에서 추가).
- max_tokens 2000은 코드의 AnthropicClient에서 분석 호출 시 파라미터로 전달. 이 task에서는 프롬프트 텍스트만 관리.

### 완료 조건 체크 방법
- `app/src/main/res/values/analysis_prompt.xml` 파일 존재 및 `R.string.analysis_system_prompt` 리소스 확인
- 프롬프트 텍스트에 "JSON" 문자가 포함되어 있고, "펜스 없이" 또는 "마크다운" 관련 지시가 있는지 확인
- 프롬프트 텍스트가 서재 전체 제목 목록을 변수(예: {existingTitles})로 참조하는 형식으로 구성되어 있는지 확인 (코드에서 String.format으로 채울 수 있게)

## 작업 메모

(2026-10-05)

- 시스템 프롬프트는 `app/src/main/res/raw/prompt_analysis_system.txt`(rules/ai-api.md: 프롬프트는 리소스 파일로). 브리핑은 strings.xml을 제안했지만 여러 문단·JSON 예시가 들어가 raw 텍스트가 읽기 쉽다.
- 내용: 요구사항 "시스템 프롬프트 요지" 4항목을 그대로 — 글귀를 핵심 근거로 "어떤 문장에 멈추는지" 해석, 장르 통계는 한 문단, 별점 높낮이 차이를 글귀·소감에서, 서재 전체 제외 5권 추천 + "당신이 저장한 ___ 글귀와 닿아 있어서" 식 이유, 출력은 JSON만(펜스 없이). 추가로 "실제 존재하는 책만, 한국어 번역본 제목" 지시를 넣었다(환각 추천 방지, 후처리 알라딘 검색 적중률).
- 제외 목록 자체는 user 메시지(`buildAnalysisInput`)에 들어가고 프롬프트는 그 절을 참조한다. system 블록에 cache_control은 붙이지 않는다(분석은 1회 호출이라 캐시 효과 없음).
- 로더는 T-606 AnalysisRepository에서 `resources.openRawResource(R.raw.prompt_analysis_system)`로 읽는다. max_tokens 2000은 호출 쪽 상수.
