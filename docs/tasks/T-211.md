### 주의할 점
- **실기기 없음**: 현재 작업 환경에는 연결된 실기기가 없다(adb devices 출력 없음). 따라서 실제 측정은 불가능하며, 측정값을 기록할 수 없다
- **측정 방법 (실기기 있을 때)**:
  1. 장치에 앱을 설치: `adb install app/build/outputs/apk/debug/app-debug.apk`
  2. 콜드 스타트 측정: `adb shell am start -W -n com.logiclinear.reading/.MainActivity` (출력에서 "ThisTime" 값 기록)
  3. 또는 logcat 확인: `adb logcat | grep "Displayed"`로 시스템이 기록한 시간 확인
  4. 5분 이상 대기 후 3회 반복 측정
- **최적화 후보**:
  - AppContainer의 lazy 초기화: Repository·OcrRecognizer 등 시작 시 불필요한 것 lazy로 변경
  - 스플래시 화면 제거 또는 단축
  - CameraX 프리뷰 바인딩을 HomeViewModel.bindCamera()에서 HomeEntry의 LaunchedEffect 시점으로 앞당기기
  - Room 데이터베이스 초기화를 백그라운드 스레드로 미루기
- **이 task에서 하면 안 되는 것**:
  - T-212 이상의 기능 추가
  - 기능 동작 변경(성능만 개선)
  - 코드 품질이 떨어지는 트릭(무의미한 병렬화, 결과 캐싱 등)
