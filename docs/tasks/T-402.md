완독 저장 시 status=DONE, rating·oneLiner·finishedAt 저장. 다시 읽기(DONE→READING)에서는 값을 유지하고 다음 완독에서 덮어쓴다. Repository 단위 테스트로 보장한다.

## 작업 브리핑

(2026-10-05, task-briefer 작성)

### 쉽게 말하면
T-401의 완독 화면에서 저장 버튼을 누르면, 책의 상태를 DONE으로 바꾸고 별점·한 줄 소감·완독일을 동시에 저장한다. 나중에 그 책을 다시 읽으러 상태를 DONE→READING으로 바꿀 때는 기존 별점과 소감을 지우지 않고 유지한다(다음 완독일 때 덮어쓴다). 이 로직을 Repository 단위 테스트로 보장한다.

### 요구사항 원문에서
- `책 상태 전이`: "READING → DONE: 완독 처리 흐름. 별점·한 줄·완독일을 받는다. DONE → READING: '다시 읽기' 버튼. 기존 별점·소감은 유지하고 완독 시 덮어쓴다." — 상태 전이와 값 유지의 핵심

### 선행 작업이 남긴 것
- T-401: FinishDialog나 화면에서 별점·한 줄·완독일을 받아 저장 요청(onSave 콜백이나 이벤트)

### 주의할 점
- setStatus(book, status)는 상태만 바꾸고 rating·oneLiner·finishedAt은 유지한다는 요구사항(현재 BookRepository 라인 34~38에 주석 있음)이 이미 구현되어 있다. 이를 활용해 DONE→READING 전이를 구현하면 된다.
- finishBook()은 새 Book 객체(status=DONE, rating·oneLiner·finishedAt 설정)를 만들어 update()해야 한다.
- 테스트는 Robolectric + Room in-memory로 한다(BookRepositoryTest 참조).

### 완료 조건 체크 방법
- 단위 테스트 실행: `./gradlew test -k BookRepositoryTest` (또는 IDE에서 BookDetailViewModelTest 실행)
- finishBook() 호출 직후 책의 status=DONE, rating/oneLiner/finishedAt이 저장된 값과 일치하는지 확인
- DONE 책에서 restartBook()을 호출한 후 status=READING으로 변경되면서 rating/oneLiner/finishedAt이 그대로 유지되는지 확인
- 책 상세 화면에서 다시 읽기 후 별점이 여전히 표시되는지 확인(T-403과 연계)

## 작업 메모

(2026-10-05)

- `domain/ReviewRules.kt`: `normalizeReview(rating, oneLiner)` 순수 함수. 별점은 1~5 밖이면 null, 한 줄은 공백 정리 후 100자에서 자르고 비면 null. `Review.isEmpty()`가 안내 문구 조건. 테스트 `ReviewRulesTest` 3개(경계 1·5·0·6, 100·150자, 빈 값).
- `BookRepository.finishBook(book, review, finishedAt)`: status DONE + rating·oneLiner·finishedAt 저장(덮어쓰기). 다시 읽기는 기존 `setStatus(book, READING)`로 값을 유지한다.
- 테스트 `BookRepositoryTest.완독_처리는_DONE으로_바꾸고_별점_소감_완독일을_저장하며_재완독은_덮어쓴다`와 기존 `상태_변경은_별점과_소감을_유지한다`(restartBook 역할).
- 브리핑의 `restartBook`은 별도 메서드로 두지 않았다. `setStatus`가 이미 그 의미이고 ViewModel의 `restartReading()`이 이름을 담당한다.

- 적대적 리뷰 반영(2026-10-05, 차단 1): ReviewSection이 DONE일 때만 보여 다시 읽기 뒤 별점이 사라졌다. `Book.hasReview()`(별점·한 줄·완독일 중 하나라도 있음)로 바꿔 상태와 무관하게 보인다. 데이터 모델 표의 "DONE일 때만"은 값이 채워지는 시점이고, 화면 표와 완료 조건은 상태 조건 없이 상세에 별점을 두므로 그쪽을 따랐다(사용자 확인 항목으로 보고).
