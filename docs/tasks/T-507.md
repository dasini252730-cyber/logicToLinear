## 작업 브리핑

### 쉽게 말하면
AI 기능(분석·토론)을 사용할 때마다 호출 횟수를 카운트하고, 설정 화면에 "이번 달 AI 호출 횟수: 3"처럼 표시한다. 저장소는 SharedPreferences/DataStore로 "2026-10" 같은 연월 키를 가진 카운트를 저장한다. 달이 바뀌면(예: 10월에서 11월로) 이전 달 카운트는 유지되지만 현재 달은 0부터 다시 센다.

### 요구사항 원문에서
- `AI 기능 > 비용 통제`: "설정 화면에 '이번 달 호출 횟수'를 단순 카운트로 표시한다." — 설정 화면에 표시할 정보
- `AI 기능 > 비용 통제`: "호출은 항상 사용자 동작(버튼, 전송)으로만 시작한다." — 호출이 일어날 때만 카운트
- `AI 기능 > 완독 후 토론`, `AI 기능 > 취향 분석·추천`: 두 가지 AI 호출 시점 (T-601, T-701에서 구현되므로, 이 task는 카운팅 인프라만)

### 선행 작업이 남긴 것
- T-501: SettingsScreen이 설정 화면이고, 여기에 호출 횟수를 표시할 공간을 마련

### 관련 파일
| 구분 | 파일 | 이유 | 줄 수 상한 |

| 수정 | app/src/main/java/com/logiclinear/reading/ui/settings/SettingsScreen.kt | "이번 달 AI 호출 횟수" 텍스트 표시 | 30 |

### 주의할 점
- **저장소**: 카운터는 비밀 정보가 아니므로 일반 SharedPreferences(기존) 또는 DataStore Preferences(1.2.1 의존)로 둘 수 있다. 프로젝트 패턴상 DataStore 추천 (T-501과 통일).
- **키 형식**: "ai_call_count_2026-10" 또는 "ai_call_count.2026-10" 같은 형식. 연월 부분은 LocalDate.now()나 YearMonth.now()로 생성. Instant.now()에서 ZoneId.systemDefault()로 로컬 시간대 고려.
- **카운터 증가**: T-601(분석), T-701(토론) 등 AI 호출 직후에 incrementAiCallCount()를 호출. 반환값은 현재 달 누적 횟수.
- **월 전환 로직**: 저장된 키의 연월과 현재 연월을 비교. 다르면 새로운 키로 카운트 시작. 기존 키는 유지 (통계용).
- **표시**: 설정 화면에 "이번 달(2026-10) 호출: 3회" 또는 "호출 횟수: 3" 정도의 단순 텍스트.

### 완료 조건 체크 방법
- `./gradlew test` AppPreferencesTest.incrementAiCallCount 테스트 통과:
  - 초기 호출 → 카운트 1 반환
  - 같은 달에 여러 번 호출 → 2, 3, 4, ... 증가
  - 달 전환(mock Instant로 10월에서 11월로 변경) → 새로운 달의 카운트 1부터 시작, 기존 10월 카운트는 남아있음
- 시뮬레이터: 설정 화면을 열어 "이번 달 AI 호출" 텍스트와 숫자가 표시되는지 확인
- 시뮬레이터: AI 호출 후 설정을 다시 열었을 때 카운트가 증가한 상태로 보이는지 확인 (T-601, T-701 구현 후)
