## 설명

isbn13이 같거나, isbn13이 없으면 제목+저자가 같은 책을 같은 책으로 본다. 같은 책이면 글귀·토론을 추가하고, 없으면 새 책으로 넣는다. 판정 함수는 순수 함수로 테스트한다.

### 주의할 점
- **ISBN 비교**: 둘 다 non-null이고 값이 같으면 같은 책. 하나라도 null이면 다음 단계(제목+저자) 확인.
- **제목+저자 비교**: 둘 다 non-null 또는 공통으로 null(드물지만 가능)일 때만. 대소문자·앞뒤 공백 정규화 필요 (trim, lowercase 또는 equalsIgnoreCase).
- **null 처리**: ISBN null + 제목 null → 불가능 (요구사항 "title은 필수"). 저자 null은 허용. 저자 중 하나가 null이면 제목만 비교할지 vs 일치하지 않는 것으로 볼지 결정. 안전하게 "둘 다 null이거나 같음" 패턴 추천.
- **정규화**: 문자열 비교 전 .trim().lowercase() 정도.
- **합치기 트랜잭션**: withTransaction 안에서 모든 INSERT, UPDATE 수행. 중간 실패 시 롤백.
- **Quote·Discussion 추가**: 같은 책을 찾았을 때, 백업의 Quote, Discussion을 새로운 Book id를 가리키도록 변환해서 삽입. 기존 Quote와 중복 추가되지 않도록 (요구사항에는 "글귀 중복"을 명시하지 않았지만, 사용자 경험상 같은 내용 글귀를 여러 번 추가하는 건 피해야 함 → 향후 고려).

### 완료 조건 체크 방법
- `./gradlew test` BookMatcherTest.isSameBook 테스트 통과:
  - Book(isbn13="978-1-234") vs Book(isbn13="978-1-234") → true
  - Book(isbn13="978-1-234") vs Book(isbn13="978-5-678") → false
  - Book(isbn13=null, title="해리포터", author="롤링") vs Book(isbn13=null, title="해리포터", author="롤링") → true
  - Book(isbn13=null, title="  해리포터  ", author="롤링") vs Book(isbn13=null, title="해리포터", author="롤링") → true (trim)
  - Book(isbn13=null, title="HARRY", author="Rowling") vs Book(isbn13=null, title="harry", author="rowling") → true (if lowercase)
- 시뮬레이터: 같은 책 내용의 백업 파일 두 개 생성 → 첫 번째 가져오기 "합치기" → 두 번째 가져오기 "합치기" → 서재에서 책이 중복되지 않았는지 확인, 글귀는 합쳐졌는지 확인
