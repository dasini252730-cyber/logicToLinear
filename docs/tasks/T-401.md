## 설명

'다 읽었어요' 버튼 → 한 화면에서 별점(1~5 별 탭), 한 줄 소감(100자 제한), 완독일(기본 오늘, 변경 가능) 입력. 둘 다 비워도 저장 가능하지만 분석 품질 안내 한 줄을 둔다.

## 완료 조건

- [ ] 한 줄 소감이 100자를 넘지 않는다
- [ ] 완독일 기본값이 오늘이고 DatePicker로 변경된다
- [ ] 비운 채 저장할 때 안내 문구가 보인다

## 작업 브리핑

### 쉽게 말하면
책을 다 읽으면 "다 읽었어요" 버튼을 눌러 별점(별 1~5개로 선택), 한 줄 소감(최대 100자), 완독한 날짜(기본값 오늘)를 입력하는 화면이 떠난다. 아무것도 입력하지 않고 저장해도 되지만, 그러면 분석 품질이 떨어진다는 안내를 본다.

### 요구사항 원문에서
- `흐름 3: 완독 처리`: "1. 책 상세 → '다 읽었어요' 버튼. 2. 한 화면에서 별점(1~5 별 탭), 한 줄 소감(텍스트 한 줄), 완독일(기본 오늘, 변경 가능) 입력 → 저장. 상태는 DONE. 3. 저장 직후 'AI와 이야기해볼까요?' 버튼 노출." — 흐름과 상태 전이의 기본
- `소감`: "별점은 1~5 정수, 한 줄은 100자 제한. 둘 다 필수는 아니지만, 비우면 분석 품질이 떨어진다는 안내 한 줄을 둔다." — 입력 제약과 빈 상태 안내

### 주의할 점
- BookDetailScreen 라인 130에서 READING 상태 버튼이 현재 disabled로 비활성되어 있다. 이 T-401에서는 onClick 이벤트만 활성화하고, T-402의 Repository 로직(상태 저장)은 아직 없어도 된다.
- 한 줄 소감 TextOutlinedField는 length validation을 해야 하므로 실시간으로 입력 길이를 제한하거나 표시해야 한다.
- 완독일 DatePicker는 androidx.compose.material3의 DatePickerDialog를 쓸 수 있다.
- "분석 품질 안내 한 줄"은 빈 상태에서만 보이고, 하나라도 입력하면 사라지는 형태를 권장한다.

### 완료 조건 체크 방법
- 책 상세에서 READING 책의 "다 읽았어요" 버튼을 눌렀을 때 입력 화면/다이얼로그가 뜨는지 확인
- 한 줄 소감에 100자를 초과해 입력하려 할 때 입력이 차단되는지 확인
- 완독일 DatePicker에서 오늘이 기본 선택되어 있는지, 다른 날짜로 변경 가능한지 확인
- 별점과 소감을 모두 비운 채 저장했을 때 "분석 품질" 안내 문구가 보이는지 확인
