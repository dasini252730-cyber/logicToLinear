### 주의할 점
- BookDetailScreen 라인 130에서 READING 상태 버튼이 현재 disabled로 비활성되어 있다. 이 T-401에서는 onClick 이벤트만 활성화하고, T-402의 Repository 로직(상태 저장)은 아직 없어도 된다.
- 한 줄 소감 TextOutlinedField는 length validation을 해야 하므로 실시간으로 입력 길이를 제한하거나 표시해야 한다.
- 완독일 DatePicker는 androidx.compose.material3의 DatePickerDialog를 쓸 수 있다.
- "분석 품질 안내 한 줄"은 빈 상태에서만 보이고, 하나라도 입력하면 사라지는 형태를 권장한다.

### 완료 조건 체크 방법
- 책 상세에서 READING 책의 "다 읽았어요" 버튼을 눌렀을 때 입력 화면/다이얼로그가 뜨는지 확인
- 한 줄 소감에 100자를 초과해 입력하려 할 때 입력이 차단되는지 확인
- 완독일 DatePicker에서 오늘이 기본 선택되어 있는지, 다른 날짜로 변경 가능한지 확인
- 별점과 소감을 모두 비운 채 저장했을 때 "분석 품질" 안내 문구가 보이는지 확인

## 작업 메모

(2026-10-05) T-401~T-405를 함께 구현.

- "다 읽었어요" 버튼(READING)이 `FinishBookSheet`(ModalBottomSheet)를 연다. 한 화면에 별점(별 5개 탭, 같은 별 다시 탭하면 해제), 한 줄 소감(100자, `n/100` 카운터), 완독일(기본 오늘, `DatePickerDialog`로 변경) → 저장. 요구사항 "흐름 3" 2단계 그대로.
- 별점·한 줄이 모두 비면 "별점과 한 줄을 비우면 분석 품질이 떨어져요" 한 줄을 보여 준다(요구사항 "소감"). 비워도 저장된다.
- 재완독이면 기존 별점·소감을 초안에 미리 채운다(저장 시 덮어쓰기, 요구사항 "다시 읽기").
- 완독일은 `LocalDate`로 다룬다. DatePicker의 epoch 밀리초는 UTC 기준으로 변환해 시간대에 따라 하루가 밀리지 않게 했다.
- 테스트 `BookDetailViewModelTest`: 입력 정리·저장·제안 표시, 별 해제·초안 채움.

- 적대적 리뷰 반영(2026-10-05): 완독일 표기를 상세와 같은 yyyy.MM.dd로 통일. 미래 완독일 허용 여부와 한 줄 100자 카운터가 앞 공백 포함으로 세는 점(저장 시 trim되어 최대 2자 차이)은 요구사항에 없어 그대로 두고 사용자 확인 항목에 올렸다.
