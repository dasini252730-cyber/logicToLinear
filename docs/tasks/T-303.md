## 설명

서재 + 버튼 → 검색창에 제목 입력 → 알라딘 결과를 표지·제목·저자로 나열한다. 로딩·빈 결과 상태를 표시하고 '직접 입력' 버튼을 항상 둔다.

- [T-302 API 키 저장소 (EncryptedSharedPreferences)](T-302.md)
- [T-110 직접 입력 책 등록 화면](T-110.md)

## 작업 브리핑

(2026-10-05, task-briefer 작성)

### 쉽게 말하면

사용자가 서재의 + 버튼을 누르면 책 제목을 검색할 수 있는 화면이 나타난다. 검색창에 입력한 제목으로 알라딘 API에 요청을 보내고, 결과를 표지 이미지와 함께 최대 10개까지 목록으로 보여준다. 로딩 상태와 빈 결과 상태를 구분해 표시하고, 모든 경우에 직접 입력 버튼이 있어 사용자는 언제든 검색을 포기하고 정보를 직접 입력할 수 있다.

### 요구사항 원문에서

- `흐름 2: 책 등록`: "서재 → + 버튼 → 검색창에 제목 입력. 알라딘 ItemSearch 결과를 표지·제목·저자로 나열." — 이 task는 검색 UI와 검색 결과 표시까지 구현한다.
- `책 검색`: "알라딘 ItemSearch (Query=제목, QueryType=Title, MaxResults=10, Cover=Big, Output=JS)." — 검색 API 호출 방식과 파라미터를 정의한다.

### 선행 작업이 남긴 것

- T-301: Retrofit 클라이언트(ItemSearch)와 SecretStore에서 TTB 키 읽기
- T-302: API 키 저장소(EncryptedSharedPreferences)
- T-110: 직접 입력 화면(BookFormScreen)

### 주의할 점

- T-301 선행 완료 필수. 알라딘 Retrofit 클라이언트(ItemSearch)가 준비되어야 한다.
- 요구사항 "흐름 2"에서 T-303은 검색 결과 표시까지만 한다. 결과를 탭해 저장하는 것은 T-304.
- T-305에서 예외 처리(결과 없음, 오프라인, 한도 초과)를 하므로, T-303에서는 성공 경로(10개 결과 표시)만 구현한다.
- 표지 이미지는 기본적인 이미지 로딩만 한다. Coil 라이브러리 추가와 디스크 캐시는 T-306에서 한다.
- 현재 LibraryScreen의 FAB는 BookFormRoute()로 이동하는데, T-303 후에 BookSearchRoute()로 변경하면 된다.

### 완료 조건 체크 방법

- 폰에서 서재 탭의 + 버튼(FAB)을 눌러 검색 화면에 진입한다.
- 책 제목(예: "해리 포터")을 입력하고 검색 결과가 표시된다.
- 검색 결과가 표지 이미지, 제목, 저자와 함께 최대 10개까지 보인다.
- 직접 입력 버튼을 눌러 BookFormScreen에 진입한다.
