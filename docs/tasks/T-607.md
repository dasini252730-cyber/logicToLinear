### 주의할 점
- 최신 결과: AnalysisDao.findLatest() 또는 유사 쿼리로 runAt 역순 첫 번째 row
- recommendationsJson 역직렬화: Json.decodeFromString<List<Recommendation>>()로 객체 배열로 변환 후 카드 렌더링. (확인 필요) T-604에서 파싱한 구조와 동일한지 확인
- 추천이 비어 있으면: recommendationsJson == "[]" 또는 decodeFromString 후 isEmpty(). 이 경우 카드 영역 전체를 `if (recommendations.isNotEmpty())`로 숨김
- 표지 로드: coverUrl이 null이면 기본 이미지(책 아이콘) 표시
- 이전 기록 목록: LazyColumn이나 Column의 expandable item. 상태는 ViewModel의 expandedAnalysisIds(Set<Long>) 같은 필드로 관리
- 날짜 포맷: runAt(Instant)을 "2026-10-05" 형식으로 표시 (요구사항에 명시 없음, 일반적 관례)

### 완료 조건 체크 방법
- `testLatestAnalysisDisplayed`: 최신 Analysis row의 tasteText와 첫 추천 카드가 화면에 보이는지 확인 (UI 테스트 또는 실기기)
- `testPreviousAnalysisCollapsed`: 이전 기록 3개가 날짜 목록으로 접혀 있고, 탭하면 펼쳐지는지 확인
- `testNoRecommendationsHidesCards`: recommendationsJson == "[]"인 분석 결과를 표시할 때 tasteText만 보이고 카드 영역은 숨겨지는지 확인
- `testCoverUrlDisplaysImage`: coverUrl이 있을 때 표지 이미지가 표시되고, null일 때 기본 아이콘이 표시되는지 확인

## 작업 메모

(2026-10-05)

- `AnalysisDao.observeAllDesc()`(runAt 내림차순)의 첫 건이 `latest`, 나머지가 `history`. 이전 기록은 "yyyy.MM.dd HH:mm 실행 · 책 N권 · 글귀 M개 기준" 한 줄만 보이고 탭하면 `AnimatedVisibility`로 같은 `AnalysisResult` 컴포저블이 펼쳐진다(한 번에 하나만 펼침).
- taste는 저장된 문자열 그대로(문단 구분 줄바꿈 유지). recommendationsJson은 `decodeRecommendations`로 풀고 깨져 있으면 빈 목록 → 카드 영역 숨김.
- 새 분석이 성공하면 `expandedId`를 비워 최신 결과가 바로 보이게 한다.

- 적대적 리뷰 반영: "이전 기록 %1$d" → "이전 기록 %1$d건".
