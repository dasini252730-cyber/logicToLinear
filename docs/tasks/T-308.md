## 설명

알라딘 OpenAPI 종료 공지(신규 키 2026-09-04 종료, 기존 키 2026-10-30 종료)와 네이버 책 검색 종료(2026-07-31)로 카카오 책 검색 API(GET v3/search/book, Authorization: KakaoAK)로 교체한다. AladinSearch/AladinResult/AladinItem을 공급자 중립 BookSearch/BookSearchResult/BookSearchItem으로 바꾸고, 설정의 TTB 키 칸을 카카오 REST API 키로, 추천 후처리 링크를 카카오 상세 URL로 바꾼다. 카카오는 분류(장르)를 주지 않아 Book.category는 비워 둔다.

## 작업 메모

(2026-10-05)

- 배경: 알라딘 OpenAPI 종료 공지(신규 인증키 발급 2026-09-04 종료, 기존 이용자 서비스 2026-10-30 종료). 네이버 책 검색 API도 2026-07-31 종료. 정보나루(승인·한도·신간 반영), Google Books(한국 도서 커버리지)보다 카카오 책 검색이 키 1개·응답 단순·표지/소개글/isbn13/링크 제공으로 현 구조에 맞아 선택.
- `data/remote/books/`: `BookSearch`(인터페이스), `BookSearchResult`(Found/Empty/NoKey/InvalidKey/ApiError/Network), `BookSearchItem`(저장 필드 7개 + link). `KakaoBookApi`(GET v3/search/book?query&target=title&size=10, 헤더 `Authorization: KakaoAK {키}`), `KakaoBookClient`(401·403 → InvalidKey, 429·400 → ApiError, 5xx·IO·직렬화 → Network). isbn은 "ISBN10 ISBN13"에서 13자리만, 저자 배열은 ", "로 합침.
- 알라딘 전용 코드(`AladinApi`, `AladinClient`, `AladinJsonCleanup`, 테스트) 삭제. `SecretKey.ALADIN_TTB` → `KAKAO_REST`(prefName kakao_rest_key). 설정 화면 칸·문구는 "카카오 REST API 키". 추천의 `aladinUrl` → `storeUrl`, 버튼 "책 정보 보기".
- 잃은 것: 분류(장르). 카카오는 category를 주지 않아 `Book.category`는 검색 등록 시 null. 분석 입력·책 상세는 null이면 그 줄을 생략하므로 동작은 그대로. 필요하면 정보나루 KDC로 보강하는 task를 따로 둔다.
- 요구사항 문서(`docs/요구사항.md`)의 알라딘 18곳과 `rules/product-principles.md`의 "도서 검색(알라딘)"은 사용자 확인 뒤 고친다.
- 2026-10-05 사용자 결정: 최종 공급자는 **국립중앙도서관 소장자료 Open API**(T-309, 인증키 승인 대기). 이 task의 카카오 구현은 임시이며, 공급자 중립 `BookSearch` 인터페이스와 호출부 교체(18개 파일)는 T-309에서 그대로 쓰인다. 요구사항·product-principles의 알라딘 표기는 T-309에서 국립중앙도서관으로 한 번에 고친다.
- 리뷰 반영: `app/build.gradle.kts` 의존성 주석의 알라딘 문구를 "책 검색"으로(차단 1). `BookSearchResult.ApiError.code`를 `Int?`→`String?`로 바꿔 NL의 본문 `errorCode`("011" 등) 문자열에도 맞게 했다(경고 3). 테스트의 알라딘 시절 코드 900을 "429"로, ISBN10만 오는 경계값 케이스 추가, 테스트 이름 정정(경고 9). CLAUDE.md 테스트 수 177개로 정정(경고 5).
- 호환 포기(경고 1): `Recommendation.aladinUrl`→`storeUrl` 이름 변경에 `@JsonNames` 호환을 두지 않았다. 실기기 설치 전이라 저장된 분석 기록·백업 파일이 없고, "aladinUrl" 문자열을 남기면 grep 0건 조건에 어긋난다.
- T-309로 이월(경고 2·4·8): isbn13 없는 검색 결과의 중복 검사, 분석 프롬프트의 장르 문단 지시, SettingsViewModel 90% 분리 계획. T-309 메모 참조.
- git 위생(경고 6): 알라딘 소스 4개 삭제가 `97d9b28`("backlog: set T-001 …") hook 커밋에 섞여 들어갔다. 파일을 지운 상태에서 backlog CLI를 호출해 hook이 삭제분까지 담은 것. 이미 push돼 되돌리지 않는다. 재발 방지: 소스 변경 중에는 backlog CLI(set·note)를 부르지 않거나, 부르기 전 작업 트리를 확인한다.
- 워크플로(경고 7): 이 task는 task-briefer 브리핑 없이 시작했다(알라딘 종료 대응을 급히 진행). T-309부터는 지킨다.
